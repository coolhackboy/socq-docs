# Google 地图 Places

获取 Google 地图 的标准化公开 Places 数据。

每个非空提交 URL 预留 `0.15` 积分。任务按每条成功返回的标准结果 `0.15` 积分结算，并退回未使用的预留积分。

## 请求体

```json
{
  "urls": [
    "https://www.google.com/maps/place/Coffee%20Project%20New%20York%20%7C%20East%20Village/data=!4m7!3m6!1s0x89c2599b5a24d7fd:0x9e354f6cf514b9fc!8m2!3d40.7270884!4d-73.9893820!16s%2Fg%2F11c3svpqld!19sChIJ_dckWptZwokR_LkU9WxPNZ4?authuser=0&hl=en&rclk=1"
  ]
}
```

## 请求限制

- `urls` 为必填字段，必须包含至少一个非空字符串；该接口不接受 `results_limit`。
- 每个值都必须能解析出 `google.com`、`goo.gl` 或两者子域名的 hostname。包含 authority 和 hostname 时可使用任意 scheme，同时支持协议相对地址。
- 运行时不要求 `/maps/place` 等特定路径；内部结果上限等于提交的非空 URL 数量。
