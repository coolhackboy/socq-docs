# Google 地图 Search

获取 Google 地图 的标准化公开 Search 数据。

成功返回的每条标准结果扣除 `0.15` 积分。列表接口按 `results_limit` 预扣并按实际结果结算。

## 请求体

```json
{
  "query": "coffee",
  "location": "New York, NY",
  "country": "US",
  "results_limit": 3
}
```

## 请求限制

- `query` 和 `location` 是必填字符串；`country`、`latitude`、`longitude`、`zoom_level` 和 `results_limit` 为选填字段。
- `latitude` 和 `longitude` 是彼此独立的数值输入；当前运行时只校验其数值类型，不限制数值范围。
- `zoom_level` 必须是 `0` 到 `21` 的整数。
- `results_limit` 必须是 `1` 到 `2,000` 的整数，默认值为 `100`。

| Exact-tool URL | `https://api.socq.ai/mcp?tools=google_maps_search` |
