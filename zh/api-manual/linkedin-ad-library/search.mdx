# LinkedIn 广告搜索

```json
{
  "company": "Microsoft",
  "countries": [
    "US"
  ],
  "results_limit": 24
}
```

`results_limit` 必须是每页 24 条的整数倍。

## 与 MCP 和 CLI 一起使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/linkedin-ad-library/search` |
| Compact MCP | `socq_execute` 与 `endpoint: "linkedin-ad-library/search"` |
| Typed MCP | `socq_linkedin_ad_library_search` |
| CLI | `socq linkedin-ad-library search` |

该接口使用异步任务流程并返回 `task_id`。轮询任务接口以读取标准化结果。
