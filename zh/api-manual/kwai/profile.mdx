# Kwai Profiles

获取 Kwai 的标准化公开 Profiles 数据。

每个成功任务固定扣除 `0.19` 积分。

## 请求体

```json
{
  "url": "https://www.kwai.com/@ShortShortz8"
}
```

## 请求限制

- `username` 与 `url` 至少提供一个；也可以同时提供，后端会将两者都转发给服务商。
- `username` 可带一个前导 `@`，随后由 1 至 64 个 ASCII 字母、数字、点、下划线或连字符组成，总长度最多为 65 个字符。
- `url` 必须为非空地址，解析后的 hostname 必须为 `kwai.com`、`kwai-video.com` 或两者的子域名。地址包含 authority 和 hostname 时可使用任意 scheme，也接受协议相对地址；裸域名、无法解析出 hostname 的地址和其他域名会被拒绝。
- 请求只接受 `username` 和 `url`。来源游标、`results_limit` 及其他请求字段会被拒绝。每个任务只发起一次服务商请求。

## 通过 MCP 使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/kwai/profile` |
| Compact MCP | `socq_execute` with `endpoint: "kwai/profile"` |
| Typed MCP | `socq_kwai_profile` |
| Exact-tool URL | `https://api.socq.ai/mcp?tools=kwai_profiles` |
| CLI | `socq kwai profile` |

<Info>
请求成功后会返回 `task_id`。使用 `socq_get_task` 查询任务，成功后从 `results.items` 读取标准化结果。
</Info>
