# Amazon Reviews

获取 Amazon 的标准化公开 Reviews 数据。

成功返回的每条标准结果扣除 `0.15` 积分。列表接口按 `results_limit` 预扣并按实际结果结算。

## 请求体

```json
{
  "urls": [
    "https://www.amazon.com/dp/B0CHHSFMRL"
  ],
  "results_limit": 20
}
```

{/* mcp-usage:start */}
## 通过 MCP 使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/amazon/reviews` |
| Compact MCP | `socq_execute` with `endpoint: "amazon/reviews"` |
| Typed MCP | `socq_amazon_reviews` |
| Exact-tool URL | `https://api.socq.ai/mcp?tools=amazon_reviews` |
| CLI | `socq amazon reviews` |

<Info>
请求成功后会返回 `task_id`。使用 `socq_get_task` 查询任务，成功后从 `results.items` 读取标准化结果。
</Info>
