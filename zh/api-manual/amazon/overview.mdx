# Amazon

| --- | --- | --- |

| 评论 | `POST` | `/v1/amazon/reviews` |
| 卖家信息 | `POST` | `/v1/amazon/sellers` |
| 畅销榜 | `POST` | `/v1/amazon/best-sellers` |
