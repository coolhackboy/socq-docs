# X 趋势

按 WOEID 采集公开的 X 趋势。结果会转换为统一结构，并按实际保存的记录数计费。

```json
{
  "woeids": [
    "1"
  ],
  "results_limit": 100
}
```

{/* mcp-usage:start */}
## 通过 MCP 使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/x/trends` |
| Compact MCP | `socq_execute`，并设置 `endpoint: "x/trends"` |
| 类型化 MCP | `socq_x_trends` |
| 精确工具 URL | `https://api.socq.ai/mcp?tools=x_trends` |
| CLI | `socq x trends` |

使用 `socq_execute` 时，将上面的 JSON 请求体作为 `input` 对象传入；也可以将相同字段直接传给类型化 MCP 工具。类型化 MCP 工具还支持 `_wait_seconds`、`_result_limit` 和 `_idempotency_key`。

<Info>
  提交成功后会返回 `task_id`。继续调用 `socq_get_task` 直到任务成功，然后从 `results.items` 读取标准化记录。
</Info>

完整的提交和轮询流程请参阅 [MCP 快速开始](/zh/integrations/mcp)。

## 标准结果字段

通过 `GET /v1/tasks/{task_id}?view=standard` 获取固定结果结构。标准视图会将来源特有的字段名和格式映射为下表所列的稳定 SocQ 字段，但不会推断或补充来源未提供的数据。MCP 查询使用 `view`/`fields`，Typed 工具使用 `_result_view`/`_result_fields`，CLI 使用 `--result-view`/`--result-fields`。声明字段在值为 `null` 时仍会保留；如需完整源数据，请使用任务结果文件。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 当前结果项的唯一标识。 |
| `platform` | `string` | 否 | 结果所属的平台，例如 `instagram` 或 `linkedin`。 |
| `resource` | `string` | 否 | 该结果对应的 SocQ 资源，例如 `videos` 或 `comments`。 |
| `type` | `string` | 否 | 结果项的类别，例如 `video`、`post` 或 `comment`。 |
| `url` | `string` | 是 | 结果项的公开访问地址（如可获得）。 |
| `published_at` | `string` | 是 | 源内容的发布时间（如可获得），使用 ISO 8601 格式。 |
| `collected_at` | `string` | 否 | SocQ 采集或处理该结果的时间，使用 ISO 8601 格式。 |
| `name` | `string` | 是 | 话题标签或趋势名称。 |
| `rank` | `integer` | 是 | 趋势在来源榜单中的排名。 |
| `region` | `string` | 是 | 地区、州或省份名称。 |
| `metrics` | `object` | 是 | 结果项可获得的计数和度量数据。 |
| `metrics.posts_count` | `integer` | 是 | 帖子数量，或与趋势关联的帖子数量。 |
| `metrics.views_count` | `integer` | 是 | 平台报告的观看数量。 |
{/* result-schema:end */}
