# X 关注列表

采集公开的 X 关注资料。结果会转换为统一结构，并按实际保存的记录数计费。

```json
{
  "usernames": [
    "@X"
  ],
  "results_limit": 200
}
```

{/* mcp-usage:start */}
## 通过 MCP 使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/x/following-list` |
| Compact MCP | `socq_execute`，并设置 `endpoint: "x/following-list"` |
| 类型化 MCP | `socq_x_following_list` |
| 精确工具 URL | `https://api.socq.ai/mcp?tools=x_following_list` |
| CLI | `socq x following-list` |

使用 `socq_execute` 时，将上面的 JSON 请求体作为 `input` 对象传入；也可以将相同字段直接传给类型化 MCP 工具。类型化 MCP 工具还支持 `_wait_seconds`、`_result_limit` 和 `_idempotency_key`。

<Info>
  提交成功后会返回 `task_id`。继续调用 `socq_get_task` 直到任务成功，然后从 `results.items` 读取标准化记录。
</Info>

完整的提交和轮询流程请参阅 [MCP 快速开始](/zh/integrations/mcp)。

## 标准结果字段

通过 `GET /v1/tasks/{task_id}?view=standard` 获取固定结果结构。标准视图会将来源特有的字段名和格式映射为下表所列的稳定 SocQ 字段，但不会推断或补充来源未提供的数据。MCP 查询使用 `view`/`fields`，Typed 工具使用 `_result_view`/`_result_fields`，CLI 使用 `--result-view`/`--result-fields`。声明字段在值为 `null` 时仍会保留；如需完整源数据，请使用任务结果文件。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 当前结果项的唯一标识。 |
| `platform` | `string` | 否 | 结果所属的平台，例如 `instagram` 或 `linkedin`。 |
| `resource` | `string` | 否 | 该结果对应的 SocQ 资源，例如 `videos` 或 `comments`。 |
| `type` | `string` | 否 | 结果项的类别，例如 `video`、`post` 或 `comment`。 |
| `url` | `string` | 是 | 结果项的公开访问地址（如可获得）。 |
| `published_at` | `string` | 是 | 源内容的发布时间（如可获得），使用 ISO 8601 格式。 |
| `collected_at` | `string` | 否 | SocQ 采集或处理该结果的时间，使用 ISO 8601 格式。 |
| `actor` | `object` | 是 | 关系中的主体账号。 |
| `actor.id` | `string` | 是 | 主体账号的唯一标识。 |
| `actor.username` | `string` | 是 | 账号的公开用户名或账号标识。 |
| `actor.name` | `string` | 是 | 主体账号的显示名称。 |
| `actor.url` | `string` | 是 | 主体账号的公开访问地址（如可获得）。 |
| `actor.avatar_url` | `string` | 是 | 账号头像图片的地址。 |
| `actor.is_verified` | `boolean` | 是 | 账号是否已通过平台认证。 |
| `actor.is_private` | `boolean` | 是 | 账号是否为私密账号。 |
| `related_actor` | `object` | 是 | 与主体账号存在关系的账号。 |
| `related_actor.id` | `string` | 是 | 关联账号的唯一标识。 |
| `related_actor.username` | `string` | 是 | 账号的公开用户名或账号标识。 |
| `related_actor.name` | `string` | 是 | 关联账号的显示名称。 |
| `related_actor.url` | `string` | 是 | 关联账号的公开访问地址（如可获得）。 |
| `related_actor.avatar_url` | `string` | 是 | 账号头像图片的地址。 |
| `related_actor.is_verified` | `boolean` | 是 | 账号是否已通过平台认证。 |
| `related_actor.is_private` | `boolean` | 是 | 账号是否为私密账号。 |
| `relationship` | `string` | 是 | 该结果表示的关系，例如 `follower`、`following` 或 `retweeter`。 |
