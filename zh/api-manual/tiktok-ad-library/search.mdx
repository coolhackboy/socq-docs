# TikTok 广告搜索

```json
{
  "query": "Anysphere",
  "results_limit": 12
}
```

`results_limit` 必须是每页 12 条的整数倍。

## 与 MCP 和 CLI 一起使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/tiktok-ad-library/search` |
| Compact MCP | `socq_execute` 与 `endpoint: "tiktok-ad-library/search"` |
| Typed MCP | `socq_tiktok_ad_library_search` |
| CLI | `socq tiktok-ad-library search` |

该接口使用异步任务流程并返回 `task_id`。轮询任务接口以读取标准化结果。
