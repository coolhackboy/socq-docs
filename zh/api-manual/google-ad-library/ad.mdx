## 标准结果字段

通过 `GET /v1/tasks/{task_id}?view=standard` 获取固定结果结构。标准视图会将来源特有的字段名和格式映射为下表所列的稳定 SocQ 字段，但不会推断或补充来源未提供的数据。MCP 查询使用 `view`/`fields`，Typed 工具使用 `_result_view`/`_result_fields`，CLI 使用 `--result-view`/`--result-fields`。声明字段在值为 `null` 时仍会保留；如需完整源数据，请使用任务结果文件。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 当前结果项的唯一标识。 |
| `platform` | `string` | 否 | 结果所属的平台，例如 `instagram` 或 `linkedin`。 |
| `resource` | `string` | 否 | 该结果对应的 SocQ 资源，例如 `videos` 或 `comments`。 |
| `type` | `string` | 否 | 结果项的类别，例如 `video`、`post` 或 `comment`。 |
| `url` | `string` | 是 | 结果项的公开访问地址（如可获得）。 |
| `published_at` | `string` | 是 | 源内容的发布时间（如可获得），使用 ISO 8601 格式。 |
| `collected_at` | `string` | 否 | SocQ 采集或处理该结果的时间，使用 ISO 8601 格式。 |
| `text` | `string` | 是 | 广告文案或创意文本。 |
| `advertiser` | `object` | 是 | 广告的投放主体。 |
| `advertiser.id` | `string` | 是 | 广告主的唯一标识。 |
| `advertiser.name` | `string` | 是 | 广告主的显示名称。 |
| `advertiser.url` | `string` | 是 | 广告主的公开访问地址（如可获得）。 |
| `advertiser.logo_url` | `string` | 是 | 公司或广告主徽标的地址。 |
| `start_date` | `string` | 是 | 广告开始投放的日期（如可获得）。 |
| `end_date` | `string` | 是 | 广告结束投放的日期（如可获得）。 |
| `countries` | `array<string>` | 是 | 广告投放的国家或地区。 |
| `platforms` | `array<string>` | 是 | 广告投放的平台或版位。 |
| `format` | `string` | 是 | 广告创意格式，例如图片或视频。 |
| `landing_page_url` | `string` | 是 | 点击广告后打开的落地页地址。 |
| `impressions` | `integer` | 是 | 广告展示次数（如有报告）。 |
| `media` | `array<object>` | 是 | 结果附带的图片、视频或其他媒体。 |
| `media.type` | `string` | 是 | 媒体类型，例如 `image` 或 `video`。 |
| `media.url` | `string` | 是 | 媒体文件的地址。 |
| `media.thumbnail_url` | `string` | 是 | 媒体预览图的地址。 |
| `media.width` | `integer` | 是 | 媒体宽度，单位为像素。 |
| `media.height` | `integer` | 是 | 媒体高度，单位为像素。 |
| `media.duration_seconds` | `number` | 是 | 媒体时长，单位为秒。 |

## 与 MCP 和 CLI 一起使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/google-ad-library/ad` |
| Compact MCP | `socq_execute` 与 `endpoint: "google-ad-library/ad"` |
| Typed MCP | `socq_google_ad_library_ad` |
| CLI | `socq google-ad-library ad` |

该接口使用异步任务流程并返回 `task_id`。轮询任务接口以读取标准化结果。
