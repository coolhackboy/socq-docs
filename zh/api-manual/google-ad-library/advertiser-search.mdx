# Google 广告主搜索

```json
{
  "query": "Nike",
  "region": "US"
}
```

接口返回本次搜索实际产生的完整结果，并按成功存储的广告主条数计费。








{/* result-schema:start */}
## 结果字段

任务结果使用下列稳定的 SocQ 字段。来源特有的字段名称和格式会被规范化，但不会推断或补充来源未提供的值。如需请求更小的字段集，MCP 查询请使用 `fields`，Typed 工具请使用 `_result_fields`，CLI 请使用 `--result-fields`。即使值为 `null`，已声明的字段仍会保留。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 当前结果项的唯一标识。 |
| `platform` | `string` | 否 | 结果所属的平台，例如 `instagram` 或 `linkedin`。 |
| `resource` | `string` | 否 | 该结果对应的 SocQ 资源，例如 `videos` 或 `comments`。 |
| `type` | `string` | 否 | 结果项的类别，例如 `video`、`post` 或 `comment`。 |
| `url` | `string` | 是 | 结果项的公开访问地址（如可获得）。 |
| `published_at` | `string` | 是 | 源内容的发布时间（如可获得），使用 ISO 8601 格式。 |
| `collected_at` | `string` | 否 | SocQ 采集或处理该结果的时间，使用 ISO 8601 格式。 |
| `name` | `string` | 是 | 广告主或机构名称。 |
| `website` | `string` | 是 | 账号、公司或广告主关联的网站。 |
| `logo_url` | `string` | 是 | 公司或广告主徽标的地址。 |
| `region` | `string` | 是 | 地区、州或省份名称。 |
| `ads_count` | `integer` | 是 | 与广告主关联的广告数量。 |
{/* result-schema:end */}

## 与 MCP 和 CLI 一起使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/google-ad-library/advertiser-search` |
| Compact MCP | `socq_execute` 与 `endpoint: "google-ad-library/advertiser-search"` |
| Typed MCP | `socq_google_ad_library_advertiser_search` |
| CLI | `socq google-ad-library advertiser-search` |

该接口使用异步任务流程并返回 `task_id`。轮询任务接口以读取标准化结果。
