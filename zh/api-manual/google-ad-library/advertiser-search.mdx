# Google 广告主搜索

```json
{
  "query": "Nike",
  "region": "US"
}
```

接口返回本次搜索实际产生的完整结果，并按成功存储的广告主条数计费。






{/* result-schema:start */}
## 标准结果字段

通过 `GET /v1/tasks/{task_id}?view=standard` 获取固定结果结构。MCP 查询使用 `view`/`fields`，Typed 工具使用 `_result_view`/`_result_fields`，CLI 使用 `--result-view`/`--result-fields`。声明字段在值为 `null` 时仍会保留；如需完整源数据，请使用任务结果文件。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 标准化的 id 字段。 |
| `platform` | `string` | 否 | 标准化的 platform 字段。 |
| `resource` | `string` | 否 | 标准化的 resource 字段。 |
| `type` | `string` | 否 | 标准化的 type 字段。 |
| `url` | `string` | 是 | 标准化的 url 字段。 |
| `published_at` | `string` | 是 | 标准化的 published at 字段。 |
| `collected_at` | `string` | 否 | 标准化的 collected at 字段。 |
| `name` | `string` | 是 | 标准化的 name 字段。 |
| `website` | `string` | 是 | 标准化的 website 字段。 |
| `logo_url` | `string` | 是 | 标准化的 logo url 字段。 |
| `region` | `string` | 是 | 标准化的 region 字段。 |
| `ads_count` | `integer` | 是 | 标准化的 ads count 字段。 |
{/* result-schema:end */}

## 与 MCP 和 CLI 一起使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/google-ad-library/advertiser-search` |
| Compact MCP | `socq_execute` 与 `endpoint: "google-ad-library/advertiser-search"` |
| Typed MCP | `socq_google_ad_library_advertiser_search` |
| CLI | `socq google-ad-library advertiser-search` |

该接口使用异步任务流程并返回 `task_id`。轮询任务接口以读取标准化结果。
