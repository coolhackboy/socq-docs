# Google 公司广告

```json
{
  "domain": "lululemon.com",
  "results_limit": 40
}
```

`results_limit` 必须是每页 40 条的整数倍。

## 与 MCP 和 CLI 一起使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/google-ad-library/company-ads` |
| Compact MCP | `socq_execute` 与 `endpoint: "google-ad-library/company-ads"` |
| Typed MCP | `socq_google_ad_library_company_ads` |
| CLI | `socq google-ad-library company-ads` |

该接口使用异步任务流程并返回 `task_id`。轮询任务接口以读取标准化结果。
