## 标准结果字段

通过 `GET /v1/tasks/{task_id}?view=standard` 获取固定结果结构。MCP 查询使用 `view`/`fields`，Typed 工具使用 `_result_view`/`_result_fields`，CLI 使用 `--result-view`/`--result-fields`。声明字段在值为 `null` 时仍会保留；如需完整源数据，请使用任务结果文件。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 标准化的 id 字段。 |
| `platform` | `string` | 否 | 标准化的 platform 字段。 |
| `resource` | `string` | 否 | 标准化的 resource 字段。 |
| `type` | `string` | 否 | 标准化的 type 字段。 |
| `url` | `string` | 是 | 标准化的 url 字段。 |
| `published_at` | `string` | 是 | 标准化的 published at 字段。 |
| `collected_at` | `string` | 否 | 标准化的 collected at 字段。 |
| `text` | `string` | 是 | 标准化的 text 字段。 |
| `author` | `object` | 是 | 标准化的 author 字段。 |
| `author.id` | `string` | 是 | 标准化的 id 字段。 |
| `author.username` | `string` | 是 | 标准化的 username 字段。 |
| `author.name` | `string` | 是 | 标准化的 name 字段。 |
| `author.url` | `string` | 是 | 标准化的 url 字段。 |
| `author.avatar_url` | `string` | 是 | 标准化的 avatar url 字段。 |
| `author.is_verified` | `boolean` | 是 | 标准化的 is verified 字段。 |
| `author.is_private` | `boolean` | 是 | 标准化的 is private 字段。 |
| `metrics` | `object` | 是 | 标准化的 metrics 字段。 |
| `metrics.likes_count` | `integer` | 是 | 标准化的 likes count 字段。 |
| `metrics.comments_count` | `integer` | 是 | 标准化的 comments count 字段。 |
| `metrics.shares_count` | `integer` | 是 | 标准化的 shares count 字段。 |
| `metrics.views_count` | `integer` | 是 | 标准化的 views count 字段。 |

| `mentions` | `array<string>` | 是 | 标准化的 mentions 字段。 |

## 与 MCP 和 CLI 一起使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/linkedin/company-posts` |
| Compact MCP | `socq_execute` 与 `endpoint: "linkedin/company-posts"` |
| Typed MCP | `socq_linkedin_company_posts` |
| CLI | `socq linkedin company-posts` |

该接口使用异步任务流程并返回 `task_id`。轮询任务接口以读取标准化结果。
