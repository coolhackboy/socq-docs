# LinkedIn 帖子搜索

```json
{
  "query": "AI agents",
  "date_posted": "last-week",
  "results_limit": 10
}
```

`results_limit` 必须是每页 10 条的整数倍。

## 与 MCP 和 CLI 一起使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/linkedin/search-posts` |
| Compact MCP | `socq_execute` 与 `endpoint: "linkedin/search-posts"` |
| Typed MCP | `socq_linkedin_search_posts` |
| CLI | `socq linkedin search-posts` |

该接口使用异步任务流程并返回 `task_id`。轮询任务接口以读取标准化结果。
