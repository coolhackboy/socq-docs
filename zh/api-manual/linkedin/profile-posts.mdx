## 与 MCP 和 CLI 一起使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/linkedin/profile-posts` |
| Compact MCP | `socq_execute` 与 `endpoint: "linkedin/profile-posts"` |
| Typed MCP | `socq_linkedin_profile_posts` |
| CLI | `socq linkedin profile-posts` |

该接口使用异步任务流程并返回 `task_id`。轮询任务接口以读取标准化结果。
