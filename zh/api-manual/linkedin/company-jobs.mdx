## 标准结果字段

| `id` | `string` | 是 | 标准化的 id 字段。 |

| `resource` | `string` | 否 | 标准化的 resource 字段。 |

## 与 MCP 和 CLI 一起使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/linkedin/company-jobs` |
| Compact MCP | `socq_execute` 与 `endpoint: "linkedin/company-jobs"` |
| Typed MCP | `socq_linkedin_company_jobs` |
| CLI | `socq linkedin company-jobs` |

该接口使用异步任务流程并返回 `task_id`。轮询任务接口以读取标准化结果。
