## 标准结果字段

通过 `GET /v1/tasks/{task_id}?view=standard` 获取固定结果结构。标准视图会将来源特有的字段名和格式映射为下表所列的稳定 SocQ 字段，但不会推断或补充来源未提供的数据。MCP 查询使用 `view`/`fields`，Typed 工具使用 `_result_view`/`_result_fields`，CLI 使用 `--result-view`/`--result-fields`。声明字段在值为 `null` 时仍会保留；如需完整源数据，请使用任务结果文件。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 当前结果项的唯一标识。 |
| `platform` | `string` | 否 | 结果所属的平台，例如 `instagram` 或 `linkedin`。 |
| `resource` | `string` | 否 | 该结果对应的 SocQ 资源，例如 `videos` 或 `comments`。 |
| `type` | `string` | 否 | 结果项的类别，例如 `video`、`post` 或 `comment`。 |
| `url` | `string` | 是 | 结果项的公开访问地址（如可获得）。 |
| `published_at` | `string` | 是 | 源内容的发布时间（如可获得），使用 ISO 8601 格式。 |
| `collected_at` | `string` | 否 | SocQ 采集或处理该结果的时间，使用 ISO 8601 格式。 |
| `title` | `string` | 是 | 职位名称。 |
| `company` | `object` | 是 | 职位所属公司。 |
| `company.id` | `string` | 是 | 公司的唯一标识。 |
| `company.name` | `string` | 是 | 公司的显示名称。 |
| `company.url` | `string` | 是 | 公司的公开访问地址（如可获得）。 |
| `company.logo_url` | `string` | 是 | 公司或广告主徽标的地址。 |
| `location` | `object` | 是 | 结果关联的地理位置信息。 |
| `location.name` | `string` | 是 | 便于阅读的地点名称。 |
| `location.city` | `string` | 是 | 城市名称。 |
| `location.region` | `string` | 是 | 地区、州或省份名称。 |
| `location.country` | `string` | 是 | 国家或地区名称或代码。 |
| `location.latitude` | `number` | 是 | 十进制度格式的纬度。 |
| `location.longitude` | `number` | 是 | 十进制度格式的经度。 |
| `text` | `string` | 是 | 职位描述。 |
| `employment_type` | `string` | 是 | 雇佣类型，例如全职、兼职或合同制。 |
| `experience_level` | `string` | 是 | 职位要求的经验或职级。 |
| `is_remote` | `boolean` | 是 | 职位是否标记为远程工作。 |
| `salary` | `object` | 是 | 职位标注的薪酬信息。 |
| `salary.amount` | `number` | 是 | 货币金额的数值。 |
| `salary.currency` | `string` | 是 | 货币金额所使用的币种代码或符号。 |
| `salary.formatted` | `string` | 是 | 便于阅读的价格或薪酬文本。 |
| `expires_at` | `string` | 是 | 职位或条目的到期时间（如可获得），使用 ISO 8601 格式。 |
{/* result-schema:end */}

## 与 MCP 和 CLI 一起使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/linkedin/search-jobs` |
| Compact MCP | `socq_execute` 与 `endpoint: "linkedin/search-jobs"` |
| Typed MCP | `socq_linkedin_search_jobs` |
| CLI | `socq linkedin search-jobs` |

该接口使用异步任务流程并返回 `task_id`。轮询任务接口以读取标准化结果。
