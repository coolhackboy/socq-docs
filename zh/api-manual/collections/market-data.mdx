## 工作流程

1. 向平台端点提交任务，例如 `POST /v1/amazon/product-search`。响应会立即返回 `task_id`。
2. 使用 `task_id` 轮询[任务状态](/zh/api-manual/agent-api/status)，或传入 `callback_url` 接收[回调](/zh/api-manual/agent-api/callbacks)。
3. 任务成功后从 `results` 读取标准化记录，或通过[任务文件](/zh/api-manual/agent-api/files)下载原始 JSONL。
