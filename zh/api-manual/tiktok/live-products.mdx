# TikTok 直播带货商品

列出一场 TikTok 直播正在卖的商品。挂了购物袋的直播间，每件商品都会带上标题、当前售价、销量、卖家和商品图。直播进行时，从 TikTok 直播搜索的结果里取出 `room_id` 和 `user_id` 即可。

```json
{
  "room_id": "7704767945901132575",
  "user_id": "7153432386608251946",
  "results_limit": 100
}
```

{/* input-contract:start */}
room_id 和 user_id 为必填项，分别取 TikTok 直播搜索结果中的 id 和 author.id。results_limit 默认 100，允许 1–500。直播间没有商品时返回空结果，不扣积分。
{/* input-contract:end */}

{/* result-schema:start */}
## 标准结果字段

任务结果使用下方稳定的 SocQ 字段。系统会统一来源特有的字段名和格式，但不会推断或补充来源未提供的数据。如需缩小返回字段集合，MCP 查询使用 `fields`，Typed 工具使用 `_result_fields`，CLI 使用 `--result-fields`。声明字段的值为 `null` 时仍会保留。

| --- | --- | --- | --- |

| `platform` | `string` | 否 | 结果所属的平台，例如 `instagram` 或 `linkedin`。 |
| `resource` | `string` | 否 | 该结果对应的 SocQ 资源，例如 `videos` 或 `comments`。 |
| `type` | `string` | 否 | 结果项的类别，例如 `video`、`post` 或 `comment`。 |
| `url` | `string` | 是 | 结果项的公开访问地址（如可获得）。 |
| `published_at` | `string` | 是 | 源内容的发布时间（如可获得），使用 ISO 8601 格式。 |
| `collected_at` | `string` | 否 | SocQ 采集或处理该结果的时间，使用 ISO 8601 格式。 |
| `title` | `string` | 是 | 商品标题。 |
| `text` | `string` | 是 | 商品描述。 |
| `seller` | `object` | 是 | 商品或条目关联的卖家。 |
| `seller.id` | `string` | 是 | 卖家的唯一标识。 |
| `seller.username` | `string` | 是 | 账号的公开用户名或账号标识。 |
| `seller.name` | `string` | 是 | 卖家的显示名称。 |
| `seller.url` | `string` | 是 | 卖家的公开访问地址（如可获得）。 |
| `seller.avatar_url` | `string` | 是 | 账号头像图片的地址。 |
| `seller.is_verified` | `boolean` | 是 | 账号是否已通过平台认证。 |
| `seller.is_private` | `boolean` | 是 | 账号是否为私密账号。 |
| `price` | `object` | 是 | 条目或商品的价格信息。 |
| `price.amount` | `number` | 是 | 货币金额的数值。 |
| `price.currency` | `string` | 是 | 货币金额所使用的币种代码或符号。 |
| `price.formatted` | `string` | 是 | 便于阅读的价格或薪酬文本。 |
| `rating` | `number` | 是 | 平台报告的商品平均评分。 |
| `reviews_count` | `integer` | 是 | 评价数量。 |
| `sold_count` | `integer` | 是 | 已售数量（如有报告）。 |
| `media` | `array<object>` | 是 | 结果附带的图片、视频或其他媒体。 |
| `media.type` | `string` | 是 | 媒体类型，例如 `image` 或 `video`。 |
| `media.url` | `string` | 是 | 媒体文件的地址。 |
| `media.thumbnail_url` | `string` | 是 | 媒体预览图的地址。 |
| `media.width` | `integer` | 是 | 媒体宽度，单位为像素。 |
| `media.height` | `integer` | 是 | 媒体高度，单位为像素。 |
| `media.duration_seconds` | `number` | 是 | 媒体时长，单位为秒。 |
