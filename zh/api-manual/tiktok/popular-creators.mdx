# TikTok 热门创作者

接口返回异步任务，完成后读取标准结果。

```json
{
  "sort_by": "engagement",
  "creator_country": "US",
  "results_limit": 20
}
```

{/* input-contract:start */}
创作者筛选条件均可选；results_limit 默认 20，允许 1–2000 的整数。
{/* input-contract:end */}

{/* result-schema:start */}
## 标准结果字段

任务结果使用下方稳定的 SocQ 字段。系统会统一来源特有的字段名和格式，但不会推断或补充来源未提供的数据。如需缩小返回字段集合，MCP 查询使用 `fields`，Typed 工具使用 `_result_fields`，CLI 使用 `--result-fields`。声明字段的值为 `null` 时仍会保留。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 当前结果项的唯一标识。 |
| `platform` | `string` | 否 | 结果所属的平台，例如 `instagram` 或 `linkedin`。 |
| `resource` | `string` | 否 | 该结果对应的 SocQ 资源，例如 `videos` 或 `comments`。 |
| `type` | `string` | 否 | 结果项的类别，例如 `video`、`post` 或 `comment`。 |
| `url` | `string` | 是 | 结果项的公开访问地址（如可获得）。 |
| `published_at` | `string` | 是 | 源内容的发布时间（如可获得），使用 ISO 8601 格式。 |
| `collected_at` | `string` | 否 | SocQ 采集或处理该结果的时间，使用 ISO 8601 格式。 |
| `username` | `string` | 是 | 账号的公开用户名或账号标识。 |
| `name` | `string` | 是 | 账号或主页的显示名称。 |
| `text` | `string` | 是 | 账号或主页的简介。 |
| `avatar_url` | `string` | 是 | 账号头像图片的地址。 |
| `cover_url` | `string` | 是 | 封面图片的地址。 |
| `website` | `string` | 是 | 账号、公司或广告主关联的网站。 |
| `is_verified` | `boolean` | 是 | 账号是否已通过平台认证。 |
| `is_private` | `boolean` | 是 | 账号是否为私密账号。 |
| `location` | `object` | 是 | 结果关联的地理位置信息。 |
| `location.name` | `string` | 是 | 便于阅读的地点名称。 |
| `location.city` | `string` | 是 | 城市名称。 |
| `location.region` | `string` | 是 | 地区、州或省份名称。 |
| `location.country` | `string` | 是 | 国家或地区名称或代码。 |
| `location.latitude` | `number` | 是 | 十进制度格式的纬度。 |
| `location.longitude` | `number` | 是 | 十进制度格式的经度。 |
| `metrics` | `object` | 是 | 结果项可获得的计数和度量数据。 |
| `metrics.followers_count` | `integer` | 是 | 粉丝数量。 |
| `metrics.following_count` | `integer` | 是 | 关注的账号数量。 |
| `metrics.posts_count` | `integer` | 是 | 帖子数量，或与趋势关联的帖子数量。 |
{/* result-schema:end */}
