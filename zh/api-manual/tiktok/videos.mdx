# TikTok 视频

为每个公共视频 URL 采集一个标准化视频记录。

```json
{
  "urls": ["https://www.tiktok.com/@example/video/7234567890123456789"]
}
```

{/* mcp-usage:start */}
## 与 MCP 一起使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/tiktok/videos` |
| Compact MCP | `socq_execute` 与 `endpoint: "tiktok/videos"` |
| Typed MCP | `socq_tiktok_videos` |
| 精确工具 URL | `https://api.socq.ai/mcp?tools=tiktok_videos` |
| CLI | `socq tiktok videos` |

使用上面的 JSON 请求正文作为 `socq_execute` 的嵌套 `input` 对象，或将相同的字段直接传递给Typed 工具。Typed 工具还接受 `_wait_seconds`、`_result_limit` 和 `_idempotency_key`。

<Info>
  成功的采集将返回 `task_id`。继续 `socq_get_task` 直到任务成功，然后从 `results.items` 读取规范化记录。
</Info>

有关完整的提交和轮询流程，请参阅[MCP 快速入门](/zh/integrations/mcp)。
{/* mcp-usage:end */}

## 标准结果字段

通过 `GET /v1/tasks/{task_id}?view=standard` 获取固定结果结构。标准视图会将来源特有的字段名和格式映射为下表所列的稳定 SocQ 字段，但不会推断或补充来源未提供的数据。MCP 查询使用 `view`/`fields`，Typed 工具使用 `_result_view`/`_result_fields`，CLI 使用 `--result-view`/`--result-fields`。声明字段在值为 `null` 时仍会保留；如需完整源数据，请使用任务结果文件。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 当前结果项的唯一标识。 |
| `platform` | `string` | 否 | 结果所属的平台，例如 `instagram` 或 `linkedin`。 |
| `resource` | `string` | 否 | 该结果对应的 SocQ 资源，例如 `videos` 或 `comments`。 |
| `type` | `string` | 否 | 结果项的类别，例如 `video`、`post` 或 `comment`。 |
| `url` | `string` | 是 | 结果项的公开访问地址（如可获得）。 |
| `published_at` | `string` | 是 | 源内容的发布时间（如可获得），使用 ISO 8601 格式。 |
| `collected_at` | `string` | 否 | SocQ 采集或处理该结果的时间，使用 ISO 8601 格式。 |
| `text` | `string` | 是 | 视频的说明文字或描述。 |
| `author` | `object` | 是 | 内容的作者或发布者。 |
| `author.id` | `string` | 是 | 作者的唯一标识。 |
| `author.username` | `string` | 是 | 账号的公开用户名或账号标识。 |
| `author.name` | `string` | 是 | 作者的显示名称。 |
| `author.url` | `string` | 是 | 作者的公开访问地址（如可获得）。 |
| `author.avatar_url` | `string` | 是 | 账号头像图片的地址。 |
| `author.is_verified` | `boolean` | 是 | 账号是否已通过平台认证。 |
| `author.is_private` | `boolean` | 是 | 账号是否为私密账号。 |
| `metrics` | `object` | 是 | 结果项可获得的计数和度量数据。 |
| `metrics.likes_count` | `integer` | 是 | 点赞数量。 |
| `metrics.comments_count` | `integer` | 是 | 评论数量。 |
| `metrics.shares_count` | `integer` | 是 | 分享或转发数量。 |
| `metrics.plays_count` | `integer` | 是 | 平台报告的视频播放次数。 |
| `metrics.views_count` | `integer` | 是 | 平台报告的观看数量。 |
| `media` | `array<object>` | 是 | 结果附带的图片、视频或其他媒体。 |
| `media.type` | `string` | 是 | 媒体类型，例如 `image` 或 `video`。 |
| `media.url` | `string` | 是 | 媒体文件的地址。 |
| `media.thumbnail_url` | `string` | 是 | 媒体预览图的地址。 |
| `media.width` | `integer` | 是 | 媒体宽度，单位为像素。 |
| `media.height` | `integer` | 是 | 媒体高度，单位为像素。 |
| `media.duration_seconds` | `number` | 是 | 媒体时长，单位为秒。 |
| `hashtags` | `array<string>` | 是 | 内容关联的话题标签，保留源数据中的拼写。 |
| `mentions` | `array<string>` | 是 | 内容中提及的账号。 |
| `shortcode` | `string` | 是 | 平台用于标识媒体内容的短代码。 |
| `duration_seconds` | `number` | 是 | 时长，单位为秒。 |
| `audio` | `object` | 是 | 视频关联的音频或音乐信息。 |
| `audio.id` | `string` | 是 | 音频或音乐曲目的标识。 |
| `audio.title` | `string` | 是 | 音频或音乐曲目的标题。 |
| `audio.artist` | `string` | 是 | 音频艺术家或创作者名称。 |
| `audio.url` | `string` | 是 | 音频或音乐曲目的地址（如可获得）。 |
