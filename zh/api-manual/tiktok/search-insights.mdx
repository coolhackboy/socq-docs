# TikTok 创作者搜索洞察

看看大家在 TikTok 上搜什么、热度往哪个方向走。每个搜索词都有 0–100 的热度分、7 个点的走势和相关视频数。把 `filter_by` 设成 `content_gap`，能找出搜得多但视频还少的词，做内容规划时很适合从这里下手。

```json
{
  "language": "en",
  "category": "food",
  "filter_by": "content_gap"
}
```

{/* input-contract:start */}
所有字段都可省略。language（默认 en）、category 和 filter_by（all 或 content_gap）决定返回哪些搜索词。每次请求返回 20 个搜索词，按次计费。
{/* input-contract:end */}

{/* result-schema:start */}
## 标准结果字段

任务结果使用下方稳定的 SocQ 字段。系统会统一来源特有的字段名和格式，但不会推断或补充来源未提供的数据。如需缩小返回字段集合，MCP 查询使用 `fields`，Typed 工具使用 `_result_fields`，CLI 使用 `--result-fields`。声明字段的值为 `null` 时仍会保留。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 当前结果项的唯一标识。 |
| `platform` | `string` | 否 | 结果所属的平台，例如 `instagram` 或 `linkedin`。 |
| `resource` | `string` | 否 | 该结果对应的 SocQ 资源，例如 `videos` 或 `comments`。 |
| `type` | `string` | 否 | 结果项的类别，例如 `video`、`post` 或 `comment`。 |
| `url` | `string` | 是 | 结果项的公开访问地址（如可获得）。 |
| `published_at` | `string` | 是 | 源内容的发布时间（如可获得），使用 ISO 8601 格式。 |
| `collected_at` | `string` | 否 | SocQ 采集或处理该结果的时间，使用 ISO 8601 格式。 |
| `keyword` | `string` | 是 | 用户在 TikTok 上搜索的词。 |
| `rank` | `integer` | 是 | 该搜索在 TikTok 列表中的位置。 |
| `popularity` | `number` | 是 | 该搜索的热度分，范围 0 到 100。 |
| `popularity_trend` | `array<number>` | 是 | 近期的热度分序列，按时间从早到晚排列，范围 0 到 100。 |
| `videos_count` | `integer` | 是 | TikTok 关联到该搜索的视频数量。 |
| `category` | `string` | 是 | 该搜索所属的内容分类。 |
| `language` | `string` | 是 | 该搜索的语言。 |
| `labels` | `array<string>` | 是 | TikTok 为该搜索标注的标签，例如 `content_gap`。 |
{/* result-schema:end */}
