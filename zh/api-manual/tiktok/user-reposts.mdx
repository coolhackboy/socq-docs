# TikTok 转发视频

转发记录能看出一个账号除了自己的作品之外，还在帮谁扩散内容。接口返回用户转发过的视频，每条都带原作者、文案、播放和点赞数、话题标签以及视频文件，方便判断这个账号偏爱哪些创作者和话题。

```json
{
  "username": "mrbeast",
  "results_limit": 20
}
```

{/* input-contract:start */}
username 为必填项。转发按时间从新到旧返回；results_limit 默认 20，允许 1–500。账号没有转发记录时返回空结果，不扣积分。
{/* input-contract:end */}

{/* result-schema:start */}
## 标准结果字段
