# TikTok 原声搜索

按歌名、歌手或曲风在 TikTok 音乐库里搜索。每条结果都有封面、时长、可试听的音频地址，以及已经用上这首音乐的视频数，适合发现正在起量的音乐；也可以先在这里确认音乐 ID，再交给 TikTok 原声视频接口拉取使用它的视频。

```json
{
  "query": "lofi",
  "results_limit": 20
}
```

{/* input-contract:start */}
query 为必填项。sort_by 可选 relevance（默认）、most_used 或 latest；region 指定搜索市场，默认 US。results_limit 默认 20，允许 1–500。
{/* input-contract:end */}

{/* result-schema:start */}
## 标准结果字段

任务结果使用下方稳定的 SocQ 字段。系统会统一来源特有的字段名和格式，但不会推断或补充来源未提供的数据。如需缩小返回字段集合，MCP 查询使用 `fields`，Typed 工具使用 `_result_fields`，CLI 使用 `--result-fields`。声明字段的值为 `null` 时仍会保留。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 当前结果项的唯一标识。 |
| `platform` | `string` | 否 | 结果所属的平台，例如 `instagram` 或 `linkedin`。 |
| `resource` | `string` | 否 | 该结果对应的 SocQ 资源，例如 `videos` 或 `comments`。 |
| `type` | `string` | 否 | 结果项的类别，例如 `video`、`post` 或 `comment`。 |
| `url` | `string` | 是 | 结果项的公开访问地址（如可获得）。 |
| `published_at` | `string` | 是 | 源内容的发布时间（如可获得），使用 ISO 8601 格式。 |
| `collected_at` | `string` | 否 | SocQ 采集或处理该结果的时间，使用 ISO 8601 格式。 |
| `name` | `string` | 是 | 原声或歌曲标题。 |
| `text` | `string` | 是 | 原声的显示标题。 |
| `author` | `object` | 是 | 内容的作者或发布者。 |
| `author.id` | `string` | 是 | 作者的唯一标识。 |
| `author.username` | `string` | 是 | 账号的公开用户名或账号标识。 |
| `author.name` | `string` | 是 | 作者的显示名称。 |
| `author.url` | `string` | 是 | 作者的公开访问地址（如可获得）。 |
| `author.avatar_url` | `string` | 是 | 账号头像图片的地址。 |
| `author.is_verified` | `boolean` | 是 | 账号是否已通过平台认证。 |
| `author.is_private` | `boolean` | 是 | 账号是否为私密账号。 |
| `cover_url` | `string` | 是 | 封面图片的地址。 |
| `duration_seconds` | `number` | 是 | 时长，单位为秒。 |
| `audio` | `object` | 是 | 原声的可播放预览。 |
| `audio.id` | `string` | 是 | 音频或音乐曲目的标识。 |
| `audio.title` | `string` | 是 | 音频或音乐曲目的标题。 |
| `audio.artist` | `string` | 是 | 音频艺术家或创作者名称。 |
| `audio.url` | `string` | 是 | 音频或音乐曲目的地址（如可获得）。 |
| `metrics` | `object` | 是 | 结果项可获得的计数和度量数据。 |
| `metrics.videos_count` | `integer` | 是 | 使用该原声的视频数量。 |
{/* result-schema:end */}
