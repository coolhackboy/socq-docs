# Facebook 个人资料活动

采集与公开 Facebook 个人资料关联的活动。结果会转换为统一结构，并按实际保存的记录数计费。

```json
{
  "urls": [
    "https://www.facebook.com/NASA"
  ],
  "results_limit": 20
}
```

{/* mcp-usage:start */}
## 通过 MCP 使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/facebook/profile-events` |
| Compact MCP | `socq_execute`，并设置 `endpoint: "facebook/profile-events"` |
| 类型化 MCP | `socq_facebook_profile_events` |
| 精确工具 URL | `https://api.socq.ai/mcp?tools=facebook_profile_events` |
| CLI | `socq facebook profile-events` |

使用 `socq_execute` 时，将上面的 JSON 请求体作为 `input` 对象传入；也可以将相同字段直接传给类型化 MCP 工具。类型化 MCP 工具还支持 `_wait_seconds`、`_result_limit` 和 `_idempotency_key`。

<Info>
  提交成功后会返回 `task_id`。继续调用 `socq_get_task` 直到任务成功，然后从 `results.items` 读取标准化记录。
</Info>

完整的提交和轮询流程请参阅 [MCP 快速开始](/zh/integrations/mcp)。

## 结果字段

任务结果使用下列稳定的 SocQ 字段。来源特有的字段名称和格式会被规范化，但不会推断或补充来源未提供的值。如需请求更小的字段集，MCP 查询请使用 `fields`，Typed 工具请使用 `_result_fields`，CLI 请使用 `--result-fields`。即使值为 `null`，已声明的字段仍会保留。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 当前结果项的唯一标识。 |
| `platform` | `string` | 否 | 结果所属的平台，例如 `instagram` 或 `linkedin`。 |
| `resource` | `string` | 否 | 该结果对应的 SocQ 资源，例如 `videos` 或 `comments`。 |
| `type` | `string` | 否 | 结果项的类别，例如 `video`、`post` 或 `comment`。 |
| `url` | `string` | 是 | 结果项的公开访问地址（如可获得）。 |
| `published_at` | `string` | 是 | 源内容的发布时间（如可获得），使用 ISO 8601 格式。 |
| `collected_at` | `string` | 否 | SocQ 采集或处理该结果的时间，使用 ISO 8601 格式。 |
| `title` | `string` | 是 | 活动标题。 |
| `text` | `string` | 是 | 活动描述。 |
| `organizer` | `object` | 是 | 活动的组织者账号或机构。 |
| `organizer.id` | `string` | 是 | 组织者的唯一标识。 |
| `organizer.username` | `string` | 是 | 账号的公开用户名或账号标识。 |
| `organizer.name` | `string` | 是 | 组织者的显示名称。 |
| `organizer.url` | `string` | 是 | 组织者的公开访问地址（如可获得）。 |
| `organizer.avatar_url` | `string` | 是 | 账号头像图片的地址。 |
| `organizer.is_verified` | `boolean` | 是 | 账号是否已通过平台认证。 |
| `organizer.is_private` | `boolean` | 是 | 账号是否为私密账号。 |
| `location` | `object` | 是 | 结果关联的地理位置信息。 |
| `location.name` | `string` | 是 | 便于阅读的地点名称。 |
| `location.city` | `string` | 是 | 城市名称。 |
| `location.region` | `string` | 是 | 地区、州或省份名称。 |
| `location.country` | `string` | 是 | 国家或地区名称或代码。 |
| `location.latitude` | `number` | 是 | 十进制度格式的纬度。 |
| `location.longitude` | `number` | 是 | 十进制度格式的经度。 |
| `start_at` | `string` | 是 | 活动开始时间（如可获得），使用 ISO 8601 格式。 |
| `end_at` | `string` | 是 | 活动结束时间（如可获得），使用 ISO 8601 格式。 |
| `media` | `array<object>` | 是 | 结果附带的图片、视频或其他媒体。 |
| `media.type` | `string` | 是 | 媒体类型，例如 `image` 或 `video`。 |
| `media.url` | `string` | 是 | 媒体文件的地址。 |
| `media.thumbnail_url` | `string` | 是 | 媒体预览图的地址。 |
| `media.width` | `integer` | 是 | 媒体宽度，单位为像素。 |
| `media.height` | `integer` | 是 | 媒体高度，单位为像素。 |
| `media.duration_seconds` | `number` | 是 | 媒体时长，单位为秒。 |
