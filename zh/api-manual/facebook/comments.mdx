# Facebook 评论

采集公共帖子 URL 的公共 Facebook 评论数据，包括评论文本、作者字段、参与度指标和原始 JSONL 输出。

## 端点

```http
POST https://api.socq.ai/v1/facebook/comments
```

## 请求正文

```json
{
  "urls": [
    "https://www.facebook.com/reel/1064194079626979/"
  ]
}
```

{/* mcp-usage:start */}
## 与 MCP 一起使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/facebook/comments` |
| Compact MCP | `socq_execute` 与 `endpoint: "facebook/comments"` |
| Typed MCP | `socq_facebook_comments` |
| 精确工具 URL | `https://api.socq.ai/mcp?tools=facebook_comments` |
| CLI | `socq facebook comments` |

使用上面的 JSON 请求正文作为 `socq_execute` 的嵌套 `input` 对象，或将相同的字段直接传递给Typed 工具。Typed 工具还接受 `_wait_seconds`、`_result_limit` 和 `_idempotency_key`。

<Info>
  成功的采集将返回 `task_id`。继续 `socq_get_task` 直到任务成功，然后从 `results.items` 读取规范化记录。
</Info>

有关完整的提交和轮询流程，请参阅[MCP 快速入门](/zh/integrations/mcp)。
{/* mcp-usage:end */}

所有返回评论均按实际结果数计费。此端点不接受结果计数限制。

## 结果字段

任务结果使用下列稳定的 SocQ 字段。来源特有的字段名称和格式会被规范化，但不会推断或补充来源未提供的值。如需请求更小的字段集，MCP 查询请使用 `fields`，Typed 工具请使用 `_result_fields`，CLI 请使用 `--result-fields`。即使值为 `null`，已声明的字段仍会保留。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 当前结果项的唯一标识。 |
| `platform` | `string` | 否 | 结果所属的平台，例如 `instagram` 或 `linkedin`。 |
| `resource` | `string` | 否 | 该结果对应的 SocQ 资源，例如 `videos` 或 `comments`。 |
| `type` | `string` | 否 | 结果项的类别，例如 `video`、`post` 或 `comment`。 |
| `url` | `string` | 是 | 结果项的公开访问地址（如可获得）。 |
| `published_at` | `string` | 是 | 源内容的发布时间（如可获得），使用 ISO 8601 格式。 |
| `collected_at` | `string` | 否 | SocQ 采集或处理该结果的时间，使用 ISO 8601 格式。 |
| `text` | `string` | 是 | 评论或回复的文本内容。 |
| `author` | `object` | 是 | 内容的作者或发布者。 |
| `author.id` | `string` | 是 | 作者的唯一标识。 |
| `author.username` | `string` | 是 | 账号的公开用户名或账号标识。 |
| `author.name` | `string` | 是 | 作者的显示名称。 |
| `author.url` | `string` | 是 | 作者的公开访问地址（如可获得）。 |
| `author.avatar_url` | `string` | 是 | 账号头像图片的地址。 |
| `author.is_verified` | `boolean` | 是 | 账号是否已通过平台认证。 |
| `author.is_private` | `boolean` | 是 | 账号是否为私密账号。 |
| `parent_id` | `string` | 是 | 回复所对应的父评论标识。 |
| `post_id` | `string` | 是 | 评论所属帖子的标识。 |
| `metrics` | `object` | 是 | 结果项可获得的计数和度量数据。 |
| `metrics.likes_count` | `integer` | 是 | 点赞数量。 |
| `metrics.replies_count` | `integer` | 是 | 回复数量。 |
| `media` | `array<object>` | 是 | 评论附带的图片、贴纸或其他媒体。 |
{/* result-schema:end */}
