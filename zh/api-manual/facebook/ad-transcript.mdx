# Facebook 广告转录

采集公开 Facebook 广告的转录文本。结果会转换为统一结构，并按实际保存的记录数计费。

```json
{
  "urls": [
    "https://www.facebook.com/ads/library?id=1545582153738441"
  ]
}
```

{/* mcp-usage:start */}
## 通过 MCP 使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/facebook/ad-transcript` |
| Compact MCP | `socq_execute`，并设置 `endpoint: "facebook/ad-transcript"` |
| 类型化 MCP | `socq_facebook_ad_transcript` |
| 精确工具 URL | `https://api.socq.ai/mcp?tools=facebook_ad_transcript` |
| CLI | `socq facebook ad-transcript` |

使用 `socq_execute` 时，将上面的 JSON 请求体作为 `input` 对象传入；也可以将相同字段直接传给类型化 MCP 工具。类型化 MCP 工具还支持 `_wait_seconds`、`_result_limit` 和 `_idempotency_key`。

<Info>
  提交成功后会返回 `task_id`。继续调用 `socq_get_task` 直到任务成功，然后从 `results.items` 读取标准化记录。
</Info>

完整的提交和轮询流程请参阅 [MCP 快速开始](/zh/integrations/mcp)。

## 标准结果字段

通过 `GET /v1/tasks/{task_id}?view=standard` 获取固定结果结构。MCP 查询使用 `view`/`fields`，Typed 工具使用 `_result_view`/`_result_fields`，CLI 使用 `--result-view`/`--result-fields`。声明字段在值为 `null` 时仍会保留；如需完整源数据，请使用任务结果文件。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 标准化的 id 字段。 |
| `platform` | `string` | 否 | 标准化的 platform 字段。 |
| `resource` | `string` | 否 | 标准化的 resource 字段。 |
| `type` | `string` | 否 | 标准化的 type 字段。 |
| `url` | `string` | 是 | 标准化的 url 字段。 |
| `published_at` | `string` | 是 | 标准化的 published at 字段。 |
| `collected_at` | `string` | 否 | 标准化的 collected at 字段。 |
| `text` | `string` | 是 | 标准化的 text 字段。 |
| `language` | `string` | 是 | 标准化的 language 字段。 |
| `format` | `string` | 是 | 标准化的 format 字段。 |
| `duration_seconds` | `number` | 是 | 标准化的 duration seconds 字段。 |
{/* result-schema:end */}
