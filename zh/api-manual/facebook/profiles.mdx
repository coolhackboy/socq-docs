# Facebook 个人资料

采集公开的 Facebook 个人资料。结果会转换为统一结构，并按实际保存的记录数计费。

```json
{
  "urls": [
    "https://www.facebook.com/NASA"
  ]
}
```

{/* mcp-usage:start */}
## 通过 MCP 使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/facebook/profiles` |
| Compact MCP | `socq_execute`，并设置 `endpoint: "facebook/profiles"` |
| 类型化 MCP | `socq_facebook_profiles` |
| 精确工具 URL | `https://api.socq.ai/mcp?tools=facebook_profiles` |
| CLI | `socq facebook profiles` |

使用 `socq_execute` 时，将上面的 JSON 请求体作为 `input` 对象传入；也可以将相同字段直接传给类型化 MCP 工具。类型化 MCP 工具还支持 `_wait_seconds`、`_result_limit` 和 `_idempotency_key`。

<Info>
  提交成功后会返回 `task_id`。继续调用 `socq_get_task` 直到任务成功，然后从 `results.items` 读取标准化记录。
</Info>

完整的提交和轮询流程请参阅 [MCP 快速开始](/zh/integrations/mcp)。

## 标准结果字段

通过 `GET /v1/tasks/{task_id}?view=standard` 获取固定结果结构。MCP 查询使用 `view`/`fields`，Typed 工具使用 `_result_view`/`_result_fields`，CLI 使用 `--result-view`/`--result-fields`。声明字段在值为 `null` 时仍会保留；如需完整源数据，请使用任务结果文件。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 标准化的 id 字段。 |
| `platform` | `string` | 否 | 标准化的 platform 字段。 |
| `resource` | `string` | 否 | 标准化的 resource 字段。 |
| `type` | `string` | 否 | 标准化的 type 字段。 |
| `url` | `string` | 是 | 标准化的 url 字段。 |
| `published_at` | `string` | 是 | 标准化的 published at 字段。 |
| `collected_at` | `string` | 否 | 标准化的 collected at 字段。 |
| `username` | `string` | 是 | 标准化的 username 字段。 |
| `name` | `string` | 是 | 标准化的 name 字段。 |
| `text` | `string` | 是 | 标准化的 text 字段。 |
| `avatar_url` | `string` | 是 | 标准化的 avatar url 字段。 |
| `cover_url` | `string` | 是 | 标准化的 cover url 字段。 |
| `website` | `string` | 是 | 标准化的 website 字段。 |
| `is_verified` | `boolean` | 是 | 标准化的 is verified 字段。 |
| `is_private` | `boolean` | 是 | 标准化的 is private 字段。 |
| `location` | `object` | 是 | 标准化的 location 字段。 |
| `location.name` | `string` | 是 | 标准化的 name 字段。 |
| `location.city` | `string` | 是 | 标准化的 city 字段。 |

| `location.country` | `string` | 是 | 标准化的 country 字段。 |
| `location.latitude` | `number` | 是 | 标准化的 latitude 字段。 |
| `location.longitude` | `number` | 是 | 标准化的 longitude 字段。 |
| `metrics` | `object` | 是 | 标准化的 metrics 字段。 |
