# 抖音 Profiles

获取 抖音 的标准化公开 Profiles 数据。

每个成功任务固定扣除 `0.10` 积分。

## 请求体

```json
{
  "user_id": "MS4wLjABAAAAW9FWcqS7RdQAWPd2AA5fL_ilmqsIFUCQ_Iym6Yh9_cUa6ZRqVLjVQSUjlHrfXY1Y"
}
```

{/* mcp-usage:start */}
## 通过 MCP 使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/douyin/profiles` |
| Compact MCP | `socq_execute` with `endpoint: "douyin/profiles"` |
| Typed MCP | `socq_douyin_profiles` |
| Exact-tool URL | `https://api.socq.ai/mcp?tools=douyin_profiles` |
| CLI | `socq douyin profiles` |

<Info>
请求成功后会返回 `task_id`。使用 `socq_get_task` 查询任务，成功后从 `results.items` 读取标准化结果。
</Info>
{/* mcp-usage:end */}
