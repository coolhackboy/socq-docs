# 抖音 Live Room Products

获取 抖音 的标准化公开 Live Room Products 数据。

每个成功任务固定扣除 `0.10` 积分。

## 请求体

```json
{
  "room_id": "7462723839303093032",
  "author_id": "82194685715",
  "results_limit": 3
}
```

{/* mcp-usage:start */}
## 通过 MCP 使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/douyin/product-data` |
| Compact MCP | `socq_execute` with `endpoint: "douyin/product-data"` |
| Typed MCP | `socq_douyin_product_data` |
| Exact-tool URL | `https://api.socq.ai/mcp?tools=douyin_live_room_products` |
| CLI | `socq douyin product-data` |

<Info>
请求成功后会返回 `task_id`。使用 `socq_get_task` 查询任务，成功后从 `results.items` 读取标准化结果。
</Info>
{/* mcp-usage:end */}
