# 抖音 Videos

获取 抖音 的标准化公开 Videos 数据。

每个成功任务固定扣除 `0.10` 积分。

## 请求体

```json
{
  "url": "https://www.douyin.com/video/7123456789012345678"
}
```

{/* mcp-usage:start */}
## 通过 MCP 使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/douyin/videos` |
| Compact MCP | `socq_execute` with `endpoint: "douyin/videos"` |
| Typed MCP | `socq_douyin_videos` |
| Exact-tool URL | `https://api.socq.ai/mcp?tools=douyin_videos` |
| CLI | `socq douyin videos` |

<Info>
请求成功后会返回 `task_id`。使用 `socq_get_task` 查询任务，成功后从 `results.items` 读取标准化结果。
</Info>
