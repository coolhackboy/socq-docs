# Snapchat Spotlight Comments

获取 Snapchat 的标准化公开 Spotlight Comments 数据。

每个成功任务固定扣除 `0.19` 积分。

## 请求体

```json
{
  "url": "https://www.snapchat.com/@queenhaley_13/spotlight/W7_EDlXWTBiXAEEniNoMPwAAYY2pnZnF0bG52AZslQsUdAZslQoRQAAAAAQ"
}
```

{/* mcp-usage:start */}
## 通过 MCP 使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/snapchat/spotlight-comments` |
| Compact MCP | `socq_execute` with `endpoint: "snapchat/spotlight-comments"` |
| Typed MCP | `socq_snapchat_spotlight_comments` |
| Exact-tool URL | `https://api.socq.ai/mcp?tools=snapchat_spotlight_comments` |
| CLI | `socq snapchat spotlight-comments` |

<Info>
请求成功后会返回 `task_id`。使用 `socq_get_task` 查询任务，成功后从 `results.items` 读取标准化结果。
</Info>
