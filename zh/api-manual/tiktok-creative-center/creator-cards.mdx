# TikTok 创意中心创作者市场

拉取候选创作者在创作者市场里的资料卡：粉丝的年龄、性别、国家和设备构成，视频播放中位数、互动率、粉丝增长率，以及他们为一条合作视频标的起步价。把 TikTok 创意中心热门视频榜里的 `creator_id` 传进来，一次最多 20 个。

```json
{
  "creator_ids": ["7011198409688219653", "7070293872819044358"]
}
```

{/* input-contract:start */}
creator_ids 为必填项，传 1–20 个创作者市场 ID，例如 TikTok 创意中心热门视频榜结果中的 creator_id。每个有资料卡的创作者返回一条结果，按条计费。
{/* input-contract:end */}

{/* result-schema:start */}
## 标准结果字段

任务结果使用下方稳定的 SocQ 字段。系统会统一来源特有的字段名和格式，但不会推断或补充来源未提供的数据。如需缩小返回字段集合，MCP 查询使用 `fields`，Typed 工具使用 `_result_fields`，CLI 使用 `--result-fields`。声明字段的值为 `null` 时仍会保留。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 创作者在 TikTok 创作者市场中的 ID。 |
| `platform` | `string` | 否 | 结果所属的平台，例如 `instagram` 或 `linkedin`。 |
| `resource` | `string` | 否 | 该结果对应的 SocQ 资源，例如 `videos` 或 `comments`。 |
| `type` | `string` | 否 | 结果项的类别，例如 `video`、`post` 或 `comment`。 |
| `url` | `string` | 是 | 结果项的公开访问地址（如可获得）。 |
| `published_at` | `string` | 是 | 源内容的发布时间（如可获得），使用 ISO 8601 格式。 |
| `collected_at` | `string` | 否 | SocQ 采集或处理该结果的时间，使用 ISO 8601 格式。 |
| `username` | `string` | 是 | 账号的公开用户名或账号标识。 |
| `name` | `string` | 是 | 结果项的显示名称。 |
| `text` | `string` | 是 | 创作者简介。 |
| `avatar_url` | `string` | 是 | 账号头像图片的地址。 |
| `region` | `string` | 是 | 创作者所在的国家或地区代码。 |
| `tiktok_user_id` | `string` | 是 | 创作者的 TikTok 数字用户 ID。 |
| `metrics` | `object` | 是 | 结果项可获得的计数和度量数据。 |
| `metrics.followers_count` | `integer` | 是 | 粉丝数量。 |
| `metrics.median_views` | `integer` | 是 | 创作者近期视频播放量的中位数。 |
| `metrics.engagement_rate` | `number` | 是 | 互动数除以播放数，取值 0 到 1 的小数。 |
| `metrics.followers_growth_rate` | `number` | 是 | 近期粉丝增长率，以小数表示。 |
| `metrics.six_second_view_rate` | `number` | 是 | 观看时长达到 6 秒的播放占比，取值 0 到 1。 |
| `starting_price` | `object` | 是 | 创作者为一条合作视频标注的起步报价。 |
| `starting_price.amount` | `number` | 是 | 货币金额的数值。 |
| `starting_price.currency` | `string` | 是 | 货币金额所使用的币种代码或符号。 |
| `starting_price.formatted` | `string` | 是 | 便于阅读的价格或薪酬文本。 |
| `audience` | `object` | 是 | 创作者粉丝的人群画像。 |
| `audience.ages` | `array<object>` | 是 | 按年龄段划分的粉丝占比。 |
| `audience.ages.label` | `string` | 是 | 分组名称，例如年龄段、性别或设备品牌。 |
| `audience.ages.share` | `number` | 是 | 占总量的比例，取值 0 到 1。 |
| `audience.genders` | `array<object>` | 是 | 按性别划分的粉丝占比。 |
| `audience.genders.label` | `string` | 是 | 分组名称，例如年龄段、性别或设备品牌。 |
| `audience.genders.share` | `number` | 是 | 占总量的比例，取值 0 到 1。 |
| `audience.countries` | `array<object>` | 是 | 广告投放的国家或地区。 |
| `audience.countries.country` | `string` | 是 | 国家或地区名称或代码。 |
| `audience.countries.country_code` | `string` | 是 | 两位字母的国家或地区代码。 |
| `audience.countries.share` | `number` | 是 | 该国家或地区粉丝所占比例，取值 0 到 1。 |
| `audience.countries.count` | `integer` | 是 | 该分组中抽样粉丝的数量。 |
| `audience.devices` | `array<object>` | 是 | 按手机品牌划分的粉丝占比。 |
| `audience.devices.label` | `string` | 是 | 分组名称，例如年龄段、性别或设备品牌。 |
| `audience.devices.share` | `number` | 是 | 占总量的比例，取值 0 到 1。 |
| `recent_video_ids` | `array<string>` | 是 | 创作者近期视频的 ID。 |
{/* result-schema:end */}
