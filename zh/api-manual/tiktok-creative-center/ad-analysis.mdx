# TikTok 创意中心广告分析

把一条热门广告按秒拆开来看。除了广告本身的信息，结果还给出点击意愿和观众留存在视频每一秒的变化，以及它的曝光量在同类广告里排在什么位置。两条曲线对照着看，开头钩子在哪、观众在哪儿流失、什么时候出手点击，一目了然。

```json
{
  "ad_id": "7697084527089729557"
}
```

{/* input-contract:start */}
ad_id 为必填项，取 TikTok 创意中心热门广告结果中的 id。返回一条分析结果，按次计费。
{/* input-contract:end */}

{/* result-schema:start */}
