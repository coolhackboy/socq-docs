# Marketplace 搜索

搜索地理坐标周围的公开列表。需要时使用[Marketplace 位置搜索](/zh/api-manual/facebook-marketplace/location-search)查找坐标。

## 请求示例

```json
{
  "query": "bike",
  "latitude": 30.2677,
  "longitude": -97.7475,
  "results_limit": 100,
  "radius_km": 65,
  "min_price": 100,
  "max_price": 500,
  "sort_by": "creation_time_descend",
  "delivery_method": "local_pickup",
  "condition": "used_good",
  "date_listed": "last_7_days",
  "availability": "available"
}
```

## 与 MCP 一起使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/facebook-marketplace/search` |
| Compact MCP | `socq_execute` 与 `endpoint: "facebook-marketplace/search"` |
| Typed MCP | `socq_facebook_marketplace_search` |
| 精确工具 URL | `https://api.socq.ai/mcp?tools=facebook_marketplace_search` |
| CLI | `socq facebook-marketplace search` |

使用上面的 JSON 请求正文作为 `socq_execute` 的嵌套 `input` 对象，或将相同的字段直接传递给Typed 工具。Typed 工具还接受 `_wait_seconds`、`_result_limit` 和 `_idempotency_key`。

<Info>
  成功的采集将返回 `task_id`。继续 `socq_get_task` 直到任务成功，然后从 `results.items` 读取规范化记录。
</Info>

有关完整的提交和轮询流程，请参阅[MCP 快速入门](/zh/integrations/mcp)。
{/* mcp-usage:end */}

SocQ 遵循结果分页，直到到达 `results_limit` 或没有其他页面可用。重复的列表 ID 会保存一次，因此最终的 `result_count` 可能会低于请求的限制。

## 标准结果字段

通过 `GET /v1/tasks/{task_id}?view=standard` 获取固定结果结构。标准视图会将来源特有的字段名和格式映射为下表所列的稳定 SocQ 字段，但不会推断或补充来源未提供的数据。MCP 查询使用 `view`/`fields`，Typed 工具使用 `_result_view`/`_result_fields`，CLI 使用 `--result-view`/`--result-fields`。声明字段在值为 `null` 时仍会保留；如需完整源数据，请使用任务结果文件。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 当前结果项的唯一标识。 |
| `platform` | `string` | 否 | 结果所属的平台，例如 `instagram` 或 `linkedin`。 |
| `resource` | `string` | 否 | 该结果对应的 SocQ 资源，例如 `videos` 或 `comments`。 |
| `type` | `string` | 否 | 结果项的类别，例如 `video`、`post` 或 `comment`。 |
| `url` | `string` | 是 | 结果项的公开访问地址（如可获得）。 |

| `title` | `string` | 是 | 条目标题。 |
| `text` | `string` | 是 | 条目描述。 |
| `seller` | `object` | 是 | 商品或条目关联的卖家。 |
| `seller.id` | `string` | 是 | 卖家的唯一标识。 |
| `seller.username` | `string` | 是 | 账号的公开用户名或账号标识。 |

| `seller.url` | `string` | 是 | 卖家的公开访问地址（如可获得）。 |

| `price` | `object` | 是 | 条目或商品的价格信息。 |
| `price.amount` | `number` | 是 | 货币金额的数值。 |

| `location.city` | `string` | 是 | 城市名称。 |
| `location.region` | `string` | 是 | 地区、州或省份名称。 |
| `location.country` | `string` | 是 | 国家或地区名称或代码。 |
| `location.latitude` | `number` | 是 | 十进制度格式的纬度。 |
