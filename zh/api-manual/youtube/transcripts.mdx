# YouTube 视频字幕

为每个公共视频 URL 采集一份纯文本视频字幕。

```json
{
  "urls": ["https://www.youtube.com/watch?v=VIDEO_ID"],
  "language": "en"
}
```

{/* mcp-usage:start */}
## 与 MCP 一起使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/youtube/transcripts` |
| Compact MCP | `socq_execute` 与 `endpoint: "youtube/transcripts"` |
| Typed MCP | `socq_youtube_transcripts` |
| 精确工具 URL | `https://api.socq.ai/mcp?tools=youtube_transcripts` |
| CLI | `socq youtube transcripts` |

使用上面的 JSON 请求正文作为 `socq_execute` 的嵌套 `input` 对象，或将相同的字段直接传递给Typed 工具。Typed 工具还接受 `_wait_seconds`、`_result_limit` 和 `_idempotency_key`。

<Info>
  成功的采集将返回 `task_id`。继续 `socq_get_task` 直到任务成功，然后从 `results.items` 读取规范化记录。
</Info>

有关完整的提交和轮询流程，请参阅[MCP 快速入门](/zh/integrations/mcp)。
{/* mcp-usage:end */}

`language` 是可选的 BCP-47 首选语言。如果不可用，则可能会返回另一种可用语言。始终使用结果的 `language` 字段作为实际的转录语言。

没有可用视频字幕的视频不会产生结果。






{/* result-schema:start */}
## 标准结果字段

通过 `GET /v1/tasks/{task_id}?view=standard` 获取固定结果结构。MCP 查询使用 `view`/`fields`，Typed 工具使用 `_result_view`/`_result_fields`，CLI 使用 `--result-view`/`--result-fields`。声明字段在值为 `null` 时仍会保留；如需完整源数据，请使用任务结果文件。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 标准化的 id 字段。 |
| `platform` | `string` | 否 | 标准化的 platform 字段。 |
| `resource` | `string` | 否 | 标准化的 resource 字段。 |
| `type` | `string` | 否 | 标准化的 type 字段。 |
| `url` | `string` | 是 | 标准化的 url 字段。 |
| `published_at` | `string` | 是 | 标准化的 published at 字段。 |
| `collected_at` | `string` | 否 | 标准化的 collected at 字段。 |
| `text` | `string` | 是 | 标准化的 text 字段。 |
| `language` | `string` | 是 | 标准化的 language 字段。 |
| `format` | `string` | 是 | 标准化的 format 字段。 |
| `duration_seconds` | `number` | 是 | 标准化的 duration seconds 字段。 |
{/* result-schema:end */}
