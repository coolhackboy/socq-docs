# YouTube 相关视频

拿到 YouTube 在视频播放页旁边推荐的“接下来观看”列表，包括标题、频道、播放量和缩略图。拿自己或竞品的视频跑一下，就能看出 YouTube 把它和哪些视频、哪些频道归在一起推荐。

```json
{
  "url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
}
```

{/* input-contract:start */}
url 为必填项，支持 watch、youtu.be、Shorts 和直播链接。一次运行返回完整的推荐列表，通常约 20 个视频，按视频条数计费。
{/* input-contract:end */}
