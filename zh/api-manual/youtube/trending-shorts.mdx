# YouTube 热门 Shorts

获取 YouTube 此刻正在推热的 Shorts，每条附带标题、频道、播放量、点赞数、评论数、时长和发布时间。每次运行都会从热门池里重新抽一批，定时跑一天下来，就能看清哪些内容正在起量。

```json
{
  "results_limit": 48
}
```

{/* input-contract:start */}
所有字段都可省略。results_limit 设置返回的 Shorts 数量（默认 48，最多 200）。每次运行抽取的是当时的热门内容，相隔几分钟的两次运行只会有少量重合。
{/* input-contract:end */}
