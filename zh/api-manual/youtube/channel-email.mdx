# YouTube 频道邮箱查找

查找 YouTube 创作者公开留下的商务邮箱，来源包括频道简介、关联的社媒主页、link-in-bio 页面和创作者自己的网站，并标明每个邮箱是在哪个页面找到的。适合整理达人建联名单：把圈好的频道逐个跑一遍，留下有联系方式的那些。

```json
{
  "url": "https://www.youtube.com/@mkbhd"
}
```

{/* input-contract:start */}
url 为必填项，填 @handle 或 /channel/UC... 形式的频道链接。找到至少一个公开邮箱时返回一条结果，包含找到的全部邮箱，计 15 积分；频道没有公开邮箱时返回空结果，不扣积分。
{/* input-contract:end */}

{/* result-schema:start */}
## 标准结果字段

任务结果使用下方稳定的 SocQ 字段。系统会统一来源特有的字段名和格式，但不会推断或补充来源未提供的数据。如需缩小返回字段集合，MCP 查询使用 `fields`，Typed 工具使用 `_result_fields`，CLI 使用 `--result-fields`。声明字段的值为 `null` 时仍会保留。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 当前结果项的唯一标识。 |
| `platform` | `string` | 否 | 结果所属的平台，例如 `instagram` 或 `linkedin`。 |
| `resource` | `string` | 否 | 该结果对应的 SocQ 资源，例如 `videos` 或 `comments`。 |
| `type` | `string` | 否 | 结果项的类别，例如 `video`、`post` 或 `comment`。 |
| `url` | `string` | 是 | 结果项的公开访问地址（如可获得）。 |
| `published_at` | `string` | 是 | 源内容的发布时间（如可获得），使用 ISO 8601 格式。 |
| `collected_at` | `string` | 否 | SocQ 采集或处理该结果的时间，使用 ISO 8601 格式。 |
| `username` | `string` | 是 | 不带 @ 的频道账号名；输入为频道 ID 时为该 ID。 |
| `name` | `string` | 是 | 频道的显示名称（如可获得）。 |
| `emails` | `array<object>` | 是 | 为该账号找到的公开联系邮箱，每个邮箱附带其出处页面。 |
| `emails.email` | `string` | 是 | 邮箱地址。 |
| `emails.source_urls` | `array<string>` | 是 | 找到该邮箱的公开页面。 |
{/* result-schema:end */}
