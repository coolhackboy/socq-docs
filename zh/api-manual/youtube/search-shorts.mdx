# YouTube Shorts 搜索

按关键词在 YouTube 上搜 Shorts，每条返回链接、文案、播放量和竖版缩略图。搜索结果只带这些基础信息，筛出想要的 Shorts 后，把链接交给 YouTube 视频接口，就能补上点赞、评论和频道资料。

```json
{
  "query": "meal prep",
  "results_limit": 25
}
```

{/* input-contract:start */}
query 为必填项。results_limit 默认 25，允许 1–200。Shorts 按 YouTube 的搜索排序返回。
{/* input-contract:end */}

{/* result-schema:start */}
