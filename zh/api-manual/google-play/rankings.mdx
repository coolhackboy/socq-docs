# Google Play Rankings

获取 Google Play 的标准化公开 Rankings 数据。

成功返回的每条标准结果扣除 `0.15` 积分。列表接口按 `results_limit` 预扣并按实际结果结算。

## 请求体

```json
{
  "urls": [
    "https://play.google.com/store/apps/category/PRODUCTIVITY"
  ],
  "results_limit": 20
}
```

## 通过 MCP 使用

| 接口 | 值 |
| --- | --- |
| REST | `POST /v1/google-play/rankings` |
| Compact MCP | `socq_execute` with `endpoint: "google-play/rankings"` |
| Typed MCP | `socq_google_play_rankings` |
| Exact-tool URL | `https://api.socq.ai/mcp?tools=google_play_rankings` |
| CLI | `socq google-play rankings` |

<Info>
请求成功后会返回 `task_id`。使用 `socq_get_task` 查询任务，成功后从 `results.items` 读取标准化结果。
</Info>
