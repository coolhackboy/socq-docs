# Instagram 帖子点赞用户

采集公开 Instagram 帖子点赞列表中显示的账号，返回用户名、显示名称、头像和认证状态。接口返回异步任务，完成后读取标准结果。

```json
{
  "url": "https://www.instagram.com/p/DRhvwVLAHAG/",
  "results_limit": 100
}
```

{/* input-contract:start */}
提供公开帖子、Reel 或 IGTV 的 url，返回该帖子点赞列表中展示的账号；results_limit 设置返回数量（默认 100，最多 1000）。
{/* input-contract:end */}

{/* result-schema:start */}
