# Instagram Reels

采集公共 Instagram Reels数据，包括标题文本、观看次数、参与度指标、媒体字段和原始 JSONL 输出。

## 端点

```http
POST https://api.socq.ai/v1/instagram/reels
```

## 请求正文

```json
{
  "usernames": ["instagram"],
  "results_limit": 10
}
```
