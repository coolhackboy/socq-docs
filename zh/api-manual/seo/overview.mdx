# SEO APIs

Use a stable, provider-independent interface for keyword and search analytics. Every operation is asynchronous: submit a task, poll its status, and read normalized records from `results.items`.

| Capability | Endpoint | 计费单位 |
| --- | --- | --- |
| Keyword search volume | `seo/keyword-search-volume` | 按请求次数计费 |
| Keyword suggestions | `seo/keyword-suggestions` | 按返回关键词数计费 |
| Related keywords | `seo/related-keywords` | 按返回关键词数计费 |
| Keyword overview | `seo/keyword-overview` | 按输入关键词数计费 |
| Keyword difficulty | `seo/keyword-difficulty` | 按输入关键词数计费 |
| Search intent | `seo/search-intent` | 按输入关键词数计费 |
| Google organic SERP | `seo/google-organic-serp` | 按返回结果数计费 |
| Ranked keywords | `seo/ranked-keywords` | 按返回关键词数计费 |
| Keywords for site | `seo/keywords-for-site` | 按返回关键词数计费 |
| Relevant pages | `seo/relevant-pages` | 按返回页面数计费 |

For market-specific results, pass `location_code` or `location_name` plus `language_code`. Database-backed endpoints default to United States and English when these fields are omitted.
