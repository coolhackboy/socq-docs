# Search Intent

```json
{"keywords":["how to research keywords","buy seo software"],"language_code":"en"}
```

Each result contains the primary intent and available intent probabilities for one input keyword.






{/* result-schema:start */}
## 标准结果字段

通过 `GET /v1/tasks/{task_id}?view=standard` 获取固定结果结构。MCP 查询使用 `view`/`fields`，Typed 工具使用 `_result_view`/`_result_fields`，CLI 使用 `--result-view`/`--result-fields`。声明字段在值为 `null` 时仍会保留；如需完整源数据，请使用任务结果文件。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 标准化的 id 字段。 |
| `platform` | `string` | 否 | 标准化的 platform 字段。 |
| `resource` | `string` | 否 | 标准化的 resource 字段。 |
| `type` | `string` | 否 | 标准化的 type 字段。 |
| `url` | `string` | 是 | 标准化的 url 字段。 |
| `published_at` | `string` | 是 | 标准化的 published at 字段。 |
| `collected_at` | `string` | 否 | 标准化的 collected at 字段。 |
| `keyword` | `string` | 是 | 标准化的 keyword 字段。 |
| `search_volume` | `integer` | 是 | 标准化的 search volume 字段。 |
| `difficulty` | `number` | 是 | 标准化的 difficulty 字段。 |
| `intent` | `string` | 是 | 标准化的 intent 字段。 |
| `cpc` | `number` | 是 | 标准化的 cpc 字段。 |
| `competition` | `number` | 是 | 标准化的 competition 字段。 |
| `rank` | `integer` | 是 | 标准化的 rank 字段。 |
| `target_url` | `string` | 是 | 标准化的 target url 字段。 |
{/* result-schema:end */}
