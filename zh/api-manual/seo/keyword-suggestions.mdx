# Keyword Suggestions

```json
{"query":"keyword research","location_code":2840,"language_code":"en","results_limit":100}
```

Each item in `results.items` is one returned keyword record. `results_limit` can be 1鈥?,000.

## 结果字段

任务结果使用下列稳定的 SocQ 字段。来源特有的字段名称和格式会被规范化，但不会推断或补充来源未提供的值。如需请求更小的字段集，MCP 查询请使用 `fields`，Typed 工具请使用 `_result_fields`，CLI 请使用 `--result-fields`。即使值为 `null`，已声明的字段仍会保留。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 当前结果项的唯一标识。 |
| `platform` | `string` | 否 | 结果所属的平台，例如 `instagram` 或 `linkedin`。 |
| `resource` | `string` | 否 | 该结果对应的 SocQ 资源，例如 `videos` 或 `comments`。 |
| `type` | `string` | 否 | 结果项的类别，例如 `video`、`post` 或 `comment`。 |
| `url` | `string` | 是 | 结果项的公开访问地址（如可获得）。 |
| `published_at` | `string` | 是 | 源内容的发布时间（如可获得），使用 ISO 8601 格式。 |
| `collected_at` | `string` | 否 | SocQ 采集或处理该结果的时间，使用 ISO 8601 格式。 |
| `keyword` | `string` | 是 | 该结果对应的关键词。 |
| `search_volume` | `integer` | 是 | 在指定周期和市场内对该关键词搜索次数的估算值。 |
| `difficulty` | `number` | 是 | 关键词排名难度的估算分值。 |
| `intent` | `string` | 是 | 识别出的关键词主要搜索意图。 |
| `cpc` | `number` | 是 | 关键词的预估单次点击费用。 |
| `competition` | `number` | 是 | 关键词的广告竞争程度。 |
| `rank` | `integer` | 是 | 目标页面针对该关键词的排名位置。 |
| `target_url` | `string` | 是 | 与关键词排名关联的页面地址。 |
{/* result-schema:end */}
