# Agent Skill

安装 `socq-social-research` Skill，让编程 Agent 学会选择 SocQ API、填写输入参数、控制成本并完成异步数据采集。

```bash
npx skills add SocQAPI/socq-devtools
```

## Agent Skill 与 MCP

| 组件 | 作用 |
| --- | --- |
| MCP | 为 Agent 提供 SocQ 工具，用于提交数据采集任务和读取结果 |
| Agent Skill | 指导 Agent 选择合适的工具，并可靠地完成调研流程 |

建议同时使用两者。MCP 负责执行；Agent Skill 负责选择 API、理解计费规则、轮询任务、翻页读取结果，以及协调跨平台调研流程。

计费行为和 API 密钥限制记录在 [API 概览](/zh/api-manual/agent-api/overview)和[身份验证](/zh/api-manual/agent-api/authentication)中。

## 使用示例

```text
收集这个 Instagram Reel 的最新评论，等待任务完成，
然后总结反复出现的正面和负面主题。
```

```text
比较这三个 X 账号的最新帖子。每个账号使用相同的结果上限，
并返回标准化的互动数据表。
```

```text
查找最近关于 AI 编程 Agent 的 YouTube 视频，收集评论，
并说明哪些主题获得了最强的受众回应。
```

该 Skill 会指导 Agent：

- 根据用户需求从能力目录中选择合适的 API；
- 选择 URL、用户名、主题标签或查询输入；
- 在运行大型任务前检查参数结构并估算所需积分；
- 提交可能需要重试的任务时使用幂等密钥；
- 轮询异步任务，而不是重复提交；
- 使用游标翻页并获取原始文件；
- 处理身份验证、参数校验、请求频率限制、积分不足和数据提供方错误；
- 组织口径一致、结果可比较的跨平台调研。

对于付费的大批量、跨平台或多端点任务，Skill 会先报告预计积分成本并请求确认，不会静默重试失败的付费请求。

## 执行优先级

该 Skill 按以下顺序选择执行方式：

1. 远程 MCP；
2. SocQ stdio MCP 转接程序；
3. MCP 不可用时使用 SocQ CLI；
4. 仅在其他方式不可用时直接使用 REST。

Skill、MCP 和 OpenAPI 使用同一份能力目录，因此不同集成方式中的 API 端点 ID 和输入字段保持一致。

## 结果与报告

该 Skill 在 MCP、CLI 和 REST 中使用相同的稳定结果结构。它将 `queued` 和 `running` 视为未完成状态，保存任务 ID 以便恢复，并沿不透明的 `next_cursor` 翻页至已批准的上限。

完成后的回复会说明所选端点和执行方式、输入与过滤条件、可用时的预计及实际积分、任务 ID 和最终状态、结果数与页数，并明确披露失败的平台、不支持的过滤条件或不完整的覆盖范围。

## 请求归属

Agent Skill 提交任务时，会在 `request_source` 中记录 Skill 及其执行方式：

| Skill 执行路径 | 记录值 |
| --- | --- |
| 远程或 stdio MCP | `skill-mcp` |
| CLI 回退 | `skill-cli` |
| 直接 REST 回退 | `skill-rest` |

该 Skill 将 `_request_source: "skill"` 传递给 MCP 执行工具，将 `--request-source skill` 传递给 CLI 命令，或将 `X-Socq-Source: skill-rest` 传递给直接 REST 请求。轮询现有任务不需要归属标记。
