# AI 与开发者集成

根据使用方式选择合适的集成。所有方案都与 Agent REST API 共用同一份能力目录、身份验证与计费规则、异步任务、标准化结果，以及数据提供方故障自动切换机制。

| 目标 | 推荐集成 | 从这里开始 |
| --- | --- | --- |
| 让 AI 客户端采集和分析数据 | MCP | [MCP 快速入门](/zh/integrations/mcp) |
| 指导 AI Agent 选择 API、控制成本并执行调研流程 | MCP + Agent Skill | [Agent Skill](/zh/integrations/skill) |
| 从终端运行采集并导出数据 | CLI | [CLI](/zh/integrations/cli) |
| 使用 HTTP 请求构建应用 | REST API | [API 概览](/zh/api-manual/agent-api/overview) |

## 最快路径

对于大多数 AI 客户端用户：

1. 设置 `SOCQ_API_KEY`。
2. 连接到 `https://api.socq.ai/mcp`；如果客户端只支持 stdio，则运行 `npx -y @socq/mcp`。
3. 要求客户端采集一个小数据集并等待返回的任务。

```text
采集这个 YouTube 视频最新的 20 条评论。
等待任务完成后，以表格形式返回评论：
https://www.youtube.com/watch?v=VIDEO_ID
```

要了解这段提示会触发哪些工具调用、如何轮询任务，以及结果的数据结构，请参阅 [MCP 快速入门](/zh/integrations/mcp)。

## 集成概览

| 集成 | 适用场景 | 安装方式或 URL | 可用性 |
| --- | --- | --- | --- |
| 远程 MCP | 支持远程连接的 AI 客户端 | `https://api.socq.ai/mcp` | 可用 |
| stdio MCP | 仅支持本地 MCP 的客户端 | `npx -y @socq/mcp` | 可用 |
| CLI | Shell 脚本和数据导出 | `npm install -g @socq/cli` | 可用 |
| Agent Skill | 可复用的调研流程 | `npx skills add SocQAPI/socq-devtools` | 从仓库安装 |

<Info>
  CLI 和 stdio MCP 都在本地运行，无需单独部署服务。远程 MCP 服务与 SocQ Agent API 一起托管。
</Info>
