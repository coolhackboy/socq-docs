# Get Amazon Sellers

Fetch normalized sellers data from Amazon.

Each successfully returned standard result costs `0.15` credits. List endpoints reserve by `results_limit` and settle against the actual result count.

## Request Body

```json
{
  "urls": [
    "https://www.amazon.com/sp?seller=EXAMPLE"
  ]
}
```

{/* mcp-usage:start */}
## Use with MCP

| Interface | Value |
| --- | --- |
| REST | `POST /v1/amazon/sellers` |
| Compact MCP | `socq_execute` with `endpoint: "amazon/sellers"` |
| Typed MCP | `socq_amazon_sellers` |
| Exact-tool URL | `https://api.socq.ai/mcp?tools=amazon_sellers` |
| CLI | `socq amazon sellers` |

<Info>
A successful request returns a `task_id`. Poll it with `socq_get_task`, then read normalized records from `results.items`.
</Info>
