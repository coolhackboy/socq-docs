# Amazon

| API | Method | Endpoint |
| --- | --- | --- |
| Product Search | `POST` | `/v1/amazon/product-search` |
| Product Details | `POST` | `/v1/amazon/product-detail` |
| Reviews | `POST` | `/v1/amazon/reviews` |
| Seller Info | `POST` | `/v1/amazon/seller-info` |
| Best Sellers | `POST` | `/v1/amazon/best-sellers` |
