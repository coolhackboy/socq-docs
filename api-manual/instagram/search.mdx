# Instagram Search

Search public Instagram profiles for username and creator discovery workflows.

## Endpoint

```http
POST https://api.socq.ai/v1/instagram/search
```

## Request Body

```json
{
  "query": "instagram",
  "results_limit": 20
}
```

## Use with MCP

| Interface | Value |
| --- | --- |
| REST | `POST /v1/instagram/search` |
| Compact MCP | `socq_execute` with `endpoint: "instagram/search"` |
| Typed MCP | `socq_instagram_search` |
| Exact-tool URL | `https://api.socq.ai/mcp?tools=instagram_search` |
| CLI | `socq instagram search` |

Use the JSON request body above as the nested `input` object for `socq_execute`, or pass the same fields directly to the typed tool. Typed tools also accept `_wait_seconds`, `_result_limit`, and `_idempotency_key`.

<Info>
  A successful collection returns a `task_id`. Continue with `socq_get_task` until the task succeeds, then read normalized records from `results.items`.
</Info>

See [MCP quickstart](/integrations/mcp) for the complete submission and polling flow.
