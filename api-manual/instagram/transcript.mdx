# Instagram Transcripts

```json
{"urls": ["https://www.instagram.com/reel/SHORTCODE/"]}
```

## Use with MCP

| Interface | Value |
| --- | --- |
| REST | `POST /v1/instagram/transcript` |
| Compact MCP | `socq_execute` with `endpoint: "instagram/transcript"` |
| Typed MCP | `socq_instagram_transcripts` |
| CLI | `socq instagram transcripts` |

Carousel posts may produce more than one transcript record. Media without speech may return no result.

## Standard Result Fields

Poll `GET /v1/tasks/{task_id}?view=standard` for the fixed result contract. The standard view maps source-specific field names and formats to the stable SocQ fields below; it does not infer or enrich values that the source did not provide. For MCP use `view`/`fields` on `socq_get_task` or `_result_view`/`_result_fields` on typed tools; CLI uses `--result-view`/`--result-fields`. Declared fields remain present when their value is `null`; use the task files for complete source data.

| Field | Type | Nullable | Description |
| --- | --- | --- | --- |
| `id` | `string` | Yes | Unique identifier for this result item. |
| `platform` | `string` | No | Platform the result belongs to, such as `instagram` or `linkedin`. |
| `resource` | `string` | No | SocQ resource represented by the result, such as `videos` or `comments`. |
| `type` | `string` | No | Category of the result item, such as `video`, `post`, or `comment`. |
| `url` | `string` | Yes | Public URL of the result item when available. |
| `published_at` | `string` | Yes | Time the source item was published, in ISO 8601 format when available. |
| `collected_at` | `string` | No | Time SocQ collected or processed this result, in ISO 8601 format. |
| `text` | `string` | Yes | Transcript text for the audio or video content. |
| `language` | `string` | Yes | Language of the transcript when available. |
| `format` | `string` | Yes | Transcript representation, such as plain text or timed segments. |
| `duration_seconds` | `number` | Yes | Duration in seconds. |
