# Google Ad Library Advertiser Search

```json
{
  "query": "Nike",
  "region": "US"
}
```

The endpoint returns the complete result set produced by the search and bills the actual number of stored advertisers.






{/* result-schema:start */}
## Standard Result Fields

Poll `GET /v1/tasks/{task_id}?view=standard` for the fixed result contract. For MCP use `view`/`fields` on `socq_get_task` or `_result_view`/`_result_fields` on typed tools; CLI uses `--result-view`/`--result-fields`. Declared fields remain present when their value is `null`; use the task files for complete source data.

| Field | Type | Nullable | Description |
| --- | --- | --- | --- |
| `id` | `string` | Yes | Normalized id field. |
| `platform` | `string` | No | Normalized platform field. |
| `resource` | `string` | No | Normalized resource field. |
| `type` | `string` | No | Normalized type field. |
| `url` | `string` | Yes | Normalized url field. |
| `published_at` | `string` | Yes | Normalized published at field. |
| `collected_at` | `string` | No | Normalized collected at field. |
| `name` | `string` | Yes | Normalized name field. |
| `website` | `string` | Yes | Normalized website field. |
| `logo_url` | `string` | Yes | Normalized logo url field. |
| `region` | `string` | Yes | Normalized region field. |
| `ads_count` | `integer` | Yes | Normalized ads count field. |
{/* result-schema:end */}

## Use with MCP and CLI

| Interface | Value |
| --- | --- |
| REST | `POST /v1/google-ad-library/advertiser-search` |
| Compact MCP | `socq_execute` with `endpoint: "google-ad-library/advertiser-search"` |
| Typed MCP | `socq_google_ad_library_advertiser_search` |
| CLI | `socq google-ad-library advertiser-search` |

The endpoint uses the asynchronous task flow and returns a task_id. Poll the task endpoint to read normalized results.
