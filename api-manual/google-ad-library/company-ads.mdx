
`results_limit` must be a multiple of the 40-record page size.

## Use with MCP and CLI

| Interface | Value |
| --- | --- |
| REST | `POST /v1/google-ad-library/company-ads` |
| Compact MCP | `socq_execute` with `endpoint: "google-ad-library/company-ads"` |
| Typed MCP | `socq_google_ad_library_company_ads` |
| CLI | `socq google-ad-library company-ads` |

The endpoint uses the asynchronous task flow and returns a task_id. Poll the task endpoint to read normalized results.
