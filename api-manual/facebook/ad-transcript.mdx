# Facebook Ad Transcript

Collect transcripts for public Facebook ads. Results are normalized and billed by the actual saved record count.

```json
{
  "urls": [
    "https://www.facebook.com/ads/library?id=1545582153738441"
  ]
}
```

{/* mcp-usage:start */}
## Use with MCP

| Interface | Value |
| --- | --- |
| REST | `POST /v1/facebook/ad-transcript` |
| Compact MCP | `socq_execute` with `endpoint: "facebook/ad-transcript"` |
| Typed MCP | `socq_facebook_ad_transcript` |
| Exact-tool URL | `https://api.socq.ai/mcp?tools=facebook_ad_transcript` |
| CLI | `socq facebook ad-transcript` |

Use the JSON request body above as the nested `input` object for `socq_execute`, or pass the same fields directly to the typed tool. Typed tools also accept `_wait_seconds`, `_result_limit`, and `_idempotency_key`.

<Info>
  A successful submission returns a `task_id`. Continue with `socq_get_task` until the task succeeds, then read normalized records from `results.items`.
</Info>

See [MCP quickstart](/integrations/mcp) for the complete submission and polling flow.
{/* mcp-usage:end */}

## Standard Result Fields

Poll `GET /v1/tasks/{task_id}?view=standard` for the fixed result contract. For MCP use `view`/`fields` on `socq_get_task` or `_result_view`/`_result_fields` on typed tools; CLI uses `--result-view`/`--result-fields`. Declared fields remain present when their value is `null`; use the task files for complete source data.

| Field | Type | Nullable | Description |
| --- | --- | --- | --- |
| `id` | `string` | Yes | Normalized id field. |
| `platform` | `string` | No | Normalized platform field. |
| `resource` | `string` | No | Normalized resource field. |
| `type` | `string` | No | Normalized type field. |
| `url` | `string` | Yes | Normalized url field. |
| `published_at` | `string` | Yes | Normalized published at field. |
| `collected_at` | `string` | No | Normalized collected at field. |
| `text` | `string` | Yes | Normalized text field. |
| `language` | `string` | Yes | Normalized language field. |
| `format` | `string` | Yes | Normalized format field. |
| `duration_seconds` | `number` | Yes | Normalized duration seconds field. |
{/* result-schema:end */}
