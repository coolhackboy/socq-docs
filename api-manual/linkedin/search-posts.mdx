# LinkedIn Search Posts

```json
{
  "query": "AI agents",
  "date_posted": "last-week",
  "results_limit": 10
}
```

`results_limit` must be a multiple of the 10-record page size.

## Standard Result Fields

Poll `GET /v1/tasks/{task_id}?view=standard` for the fixed result contract. For MCP use `view`/`fields` on `socq_get_task` or `_result_view`/`_result_fields` on typed tools; CLI uses `--result-view`/`--result-fields`. Declared fields remain present when their value is `null`; use the task files for complete source data.

## Use with MCP and CLI

| Interface | Value |
| --- | --- |
| REST | `POST /v1/linkedin/search-posts` |
| Compact MCP | `socq_execute` with `endpoint: "linkedin/search-posts"` |
| Typed MCP | `socq_linkedin_search_posts` |
| CLI | `socq linkedin search-posts` |

The endpoint uses the asynchronous task flow and returns a task_id. Poll the task endpoint to read normalized results.
