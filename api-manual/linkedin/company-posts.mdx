## Standard Result Fields

The standard view maps source-specific field names and formats to the stable SocQ fields below; it does not infer or enrich values that the source did not provide. For MCP use `view`/`fields` on `socq_get_task` or `_result_view`/`_result_fields` on typed tools; CLI uses `--result-view`/`--result-fields`. ## Use with MCP and CLI

| Interface | Value |
| --- | --- |
| REST | `POST /v1/linkedin/company-posts` |
| Compact MCP | `socq_execute` with `endpoint: "linkedin/company-posts"` |
| Typed MCP | `socq_linkedin_company_posts` |
| CLI | `socq linkedin company-posts` |

The endpoint uses the asynchronous task flow and returns a task_id. Poll the task endpoint to read normalized results.
