# LinkedIn Profile Posts

```json
{
  "urls": [
    "https://www.linkedin.com/in/satyanadella/"
  ],
  "only_authored_posts": true,
  "results_limit": 20
}
```

## Use with MCP and CLI

| Interface | Value |
| --- | --- |
| REST | `POST /v1/linkedin/profile-posts` |
| Compact MCP | `socq_execute` with `endpoint: "linkedin/profile-posts"` |
| Typed MCP | `socq_linkedin_profile_posts` |
| CLI | `socq linkedin profile-posts` |

The endpoint uses the asynchronous task flow and returns a task_id. Poll the task endpoint to read normalized results.
