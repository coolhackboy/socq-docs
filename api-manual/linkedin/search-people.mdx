# LinkedIn People Search

```json
{
  "urls": [
    "https://www.linkedin.com/search/results/people/?keywords=engineer"
  ],
  "results_limit": 20
}
```

## Use with MCP and CLI

| Interface | Value |
| --- | --- |
| REST | `POST /v1/linkedin/search-people` |
| Compact MCP | `socq_execute` with `endpoint: "linkedin/search-people"` |
| Typed MCP | `socq_linkedin_search_people` |
| CLI | `socq linkedin search-people` |

The endpoint uses the asynchronous task flow and returns a task_id. Poll the task endpoint to read normalized results.
