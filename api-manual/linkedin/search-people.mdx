# LinkedIn People Search

```json
{
  "urls": [
    "https://www.linkedin.com/search/results/people/?keywords=Aakash%20Gupta"
  ]
}
```

This endpoint returns all records produced for each submitted search URL. The data source does not support a result limit, so usage is billed from the actual number of stored results.

## Standard Result Fields

Poll `GET /v1/tasks/{task_id}?view=standard` for the fixed result contract. For MCP use `view`/`fields` on `socq_get_task` or `_result_view`/`_result_fields` on typed tools; CLI uses `--result-view`/`--result-fields`. ## Use with MCP and CLI

| Interface | Value |
| --- | --- |
| REST | `POST /v1/linkedin/search-people` |
| Compact MCP | `socq_execute` with `endpoint: "linkedin/search-people"` |
| Typed MCP | `socq_linkedin_search_people` |
| CLI | `socq linkedin search-people` |

The endpoint uses the asynchronous task flow and returns a task_id. Poll the task endpoint to read normalized results.
