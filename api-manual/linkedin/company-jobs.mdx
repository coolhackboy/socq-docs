## Use with MCP and CLI

| Interface | Value |
| --- | --- |
| REST | `POST /v1/linkedin/company-jobs` |
| Compact MCP | `socq_execute` with `endpoint: "linkedin/company-jobs"` |
| Typed MCP | `socq_linkedin_company_jobs` |
| CLI | `socq linkedin company-jobs` |

The endpoint uses the asynchronous task flow and returns a task_id. Poll the task endpoint to read normalized results.
