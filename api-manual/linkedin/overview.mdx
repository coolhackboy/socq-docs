# LinkedIn

| API | Method | Endpoint |
| --- | --- | --- |
| Profiles | `POST` | `/v1/linkedin/profiles` |
| Companies | `POST` | `/v1/linkedin/companies` |
| Posts | `POST` | `/v1/linkedin/posts` |
| Jobs | `POST` | `/v1/linkedin/jobs` |

Each endpoint accepts public LinkedIn URLs and uses the standard asynchronous task flow.

| post-comments | `POST` | `/v1/linkedin/post-comments` |
| search-posts | `POST` | `/v1/linkedin/search-posts` |
| company-posts | `POST` | `/v1/linkedin/company-posts` |
| profile-posts | `POST` | `/v1/linkedin/profile-posts` |
| search-people | `POST` | `/v1/linkedin/search-people` |
| search-jobs | `POST` | `/v1/linkedin/search-jobs` |
| company-jobs | `POST` | `/v1/linkedin/company-jobs` |
