# Keyword Search Volume

```json
{"keywords":["keyword research","seo tools"],"location_code":2840,"language_code":"en"}
```

Accepts up to 1,000 keywords. Each returned record corresponds to a keyword for which metrics are available. Similar keywords can occasionally share aggregated search-volume values.
