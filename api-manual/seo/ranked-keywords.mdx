# Ranked Keywords

```json
{
  "target": "microsoft.com",
  "location_code": 2840,
  "language_code": "en",
  "results_limit": 5
}
```

Each item is one ranked keyword record with keyword metrics and the matching search-result position.

For MCP use `view`/`fields` on `socq_get_task` or `_result_view`/`_result_fields` on typed tools; CLI uses `--result-view`/`--result-fields`.
