# Keyword Suggestions

```json
{"query":"keyword research","location_code":2840,"language_code":"en","results_limit":100}
```

Each item in `results.items` is one returned keyword record. `results_limit` can be 1–1,000.

## Standard Result Fields

For MCP use `view`/`fields` on `socq_get_task` or `_result_view`/`_result_fields` on typed tools; CLI uses `--result-view`/`--result-fields`.
