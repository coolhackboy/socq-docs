# SEO APIs

Use a stable, provider-independent interface for keyword and search analytics. Every operation is asynchronous: submit a task, poll its status, and read normalized records from `results.items`.

| Capability | Endpoint | Billing unit |
| --- | --- | --- |
| Keyword search volume | `seo/keyword-search-volume` | Per request |
| Keyword suggestions | `seo/keyword-suggestions` | Per returned keyword |
| Related keywords | `seo/related-keywords` | Per returned keyword |
| Keyword overview | `seo/keyword-overview` | Per input keyword |
| Keyword difficulty | `seo/keyword-difficulty` | Per input keyword |
| Search intent | `seo/search-intent` | Per input keyword |
| Google organic SERP | `seo/google-organic-serp` | Per returned result |
| Ranked keywords | `seo/ranked-keywords` | Per returned keyword |
| Keywords for site | `seo/keywords-for-site` | Per returned keyword |
| Relevant pages | `seo/relevant-pages` | Per returned page |

For market-specific results, pass `location_code` or `location_name` plus `language_code`. Database-backed endpoints default to United States and English when these fields are omitted.
