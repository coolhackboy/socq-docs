# Google Organic SERP

```json
{"query":"keyword research","location_code":2840,"language_code":"en","device":"desktop","results_limit":10}
```

Each item is one search-result element with its URL, title, rank, and available enriched fields.






{/* result-schema:start */}
## Standard Result Fields

Poll `GET /v1/tasks/{task_id}?view=standard` for the fixed result contract. For MCP use `view`/`fields` on `socq_get_task` or `_result_view`/`_result_fields` on typed tools; CLI uses `--result-view`/`--result-fields`. Declared fields remain present when their value is `null`; use the task files for complete source data.

| Field | Type | Nullable | Description |
| --- | --- | --- | --- |
| `id` | `string` | Yes | Normalized id field. |
| `platform` | `string` | No | Normalized platform field. |
| `resource` | `string` | No | Normalized resource field. |
| `type` | `string` | No | Normalized type field. |
| `url` | `string` | Yes | Normalized url field. |
| `published_at` | `string` | Yes | Normalized published at field. |
| `collected_at` | `string` | No | Normalized collected at field. |
| `title` | `string` | Yes | Normalized title field. |
| `text` | `string` | Yes | Normalized text field. |
| `rank` | `integer` | Yes | Normalized rank field. |
| `domain` | `string` | Yes | Normalized domain field. |
| `result_type` | `string` | Yes | Normalized result type field. |
{/* result-schema:end */}
