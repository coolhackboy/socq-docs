# Rednote

| API | Method | Endpoint |
| --- | --- | --- |
| Note Details | `POST` | `/v1/rednote/notes` |
| Profiles | `POST` | `/v1/rednote/profiles` |
| User Notes | `POST` | `/v1/rednote/user-notes` |
| Note Search | `POST` | `/v1/rednote/search` |
| User Search | `POST` | `/v1/rednote/search-users` |
| Note Comments | `POST` | `/v1/rednote/comments` |
| Comment Replies | `POST` | `/v1/rednote/comment-replies` |
| Home Recommendations | `POST` | `/v1/rednote/home-recommendations` |
