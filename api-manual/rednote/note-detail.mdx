# Get Rednote Notes

Fetch normalized notes data from Rednote.

Each successful task costs a fixed `1.00` credits.

## Request Body

```json
{
  "url": "https://www.xiaohongshu.com/explore/6a2f423d000000001003cb36?xsec_token=ABtexB6bX5HgLD42SFrK1scGUmSO8YV5_isaLrDy9sLxQ%3D"
}
```

## Use with MCP

| Interface | Value |
| --- | --- |
| REST | `POST /v1/rednote/note-detail` |
| Compact MCP | `socq_execute` with `endpoint: "rednote/note-detail"` |
| Typed MCP | `socq_rednote_note_detail` |
| Exact-tool URL | `https://api.socq.ai/mcp?tools=rednote_notes` |
| CLI | `socq rednote note-detail` |

<Info>
A successful request returns a `task_id`. Poll it with `socq_get_task`, then read normalized records from `results.items`.
</Info>
