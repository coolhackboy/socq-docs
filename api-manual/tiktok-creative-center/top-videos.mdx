# TikTok Creative Center Top Videos

Pull TikTok's chart of top-performing videos for a country, ranked by views, engagement rate or six-second view rate. Each entry carries the caption, the creator, views in the chart period, lifetime views and engagement metrics. When a creator stands out, pass their `creator_id` to TikTok Creative Center Creator Marketplace for audience and rate details.

```json
{
  "country": "US",
  "period": "daily",
  "results_limit": 20
}
```

{/* input-contract:start */}
All fields are optional. country defaults to US, period picks the daily (default), weekly or long_term chart, and sort_by ranks by views (default), engagement_rate or six_second_view_rate. The latest published chart is used. results_limit defaults to 20 and accepts 1 to 100.
{/* input-contract:end */}
