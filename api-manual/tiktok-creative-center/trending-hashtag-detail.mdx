# TikTok Creative Center Hashtag Insights

Dig into a single trending hashtag: its post and view totals, the daily popularity curve, the countries where it is most popular for their size and a set of example videos. The `id` from TikTok Creative Center Trending Hashtags plugs straight in.

```json
{
  "hashtag_id": "7155204034885287979",
  "country": "US",
  "time_range": "7d"
}
```

{/* input-contract:start */}
hashtag_id is required; use the id of a TikTok Creative Center Trending Hashtags result together with the same country. time_range (default 7d) picks the period. Returns one result, billed once.
{/* input-contract:end */}

## Standard Result Fields

Task results use the stable SocQ fields below. Source-specific field names and formats are normalized without inferring or enriching values that the source did not provide. To request a smaller field set, use `fields` for MCP queries, `_result_fields` for typed tools, or `--result-fields` in the CLI. Declared fields remain present when their value is `null`.

| Field | Type | Nullable | Description |
| --- | --- | --- | --- |
| `id` | `string` | Yes | Hashtag ID, accepted by Trending Hashtag Detail. |
| `platform` | `string` | No | Platform the result belongs to, such as `instagram` or `linkedin`. |
| `resource` | `string` | No | SocQ resource represented by the result, such as `videos` or `comments`. |
| `type` | `string` | No | Category of the result item, such as `video`, `post`, or `comment`. |
| `url` | `string` | Yes | Public URL of the result item when available. |
| `published_at` | `string` | Yes | Time the source item was published, in ISO 8601 format when available. |
| `collected_at` | `string` | No | Time SocQ collected or processed this result, in ISO 8601 format. |
| `name` | `string` | Yes | Hashtag name without the # prefix. |
| `rank` | `integer` | Yes | Position of the hashtag in the trending ranking. |
| `region` | `string` | Yes | Country or region code the ranking covers. |
| `metrics` | `object` | Yes | Counters and measurements available for the result item. |
| `metrics.posts_count` | `integer` | Yes | Number of posts or posts associated with the trend. |
| `metrics.views_count` | `integer` | Yes | Number of views reported by the platform. |
| `popularity_curve` | `array<object>` | Yes | Daily popularity of the hashtag over the period, on a 0 to 100 scale. |
| `popularity_curve.date` | `string` | Yes | Date of the data point, in YYYY-MM-DD format. |
| `popularity_curve.value` | `number` | Yes | Value at this point of the curve. |
| `top_countries` | `array<object>` | Yes | Countries where the hashtag is most popular relative to their size, highest score first. |
| `top_countries.country_code` | `string` | Yes | Two-letter country or region code. |
| `top_countries.score` | `number` | Yes | Score reported for the entry. |
| `video_ids` | `array<string>` | Yes | IDs of example videos that use the hashtag. |
