# TikTok Creative Center Trending Hashtags

See which hashtags are climbing in a given country. The ranking gives each hashtag's position, post count, views and a daily popularity curve for the period, across markets such as US, GB and JP. Any tag worth a closer look can go straight into TikTok Creative Center Hashtag Insights.

```json
{
  "country": "US",
  "time_range": "7d",
  "results_limit": 20
}
```

{/* input-contract:start */}
All fields are optional. country (default US) and time_range (7d by default, or 30d or 90d) choose the ranking. results_limit defaults to 20 and accepts 1 to 100.
{/* input-contract:end */}

## Standard Result Fields

Task results use the stable SocQ fields below. Source-specific field names and formats are normalized without inferring or enriching values that the source did not provide. To request a smaller field set, use `fields` for MCP queries, `_result_fields` for typed tools, or `--result-fields` in the CLI. Declared fields remain present when their value is `null`.

| Field | Type | Nullable | Description |

| `resource` | `string` | No | SocQ resource represented by the result, such as `videos` or `comments`. |

| `url` | `string` | Yes | Public URL of the result item when available. |
| `published_at` | `string` | Yes | Time the source item was published, in ISO 8601 format when available. |
| `collected_at` | `string` | No | Time SocQ collected or processed this result, in ISO 8601 format. |
| `name` | `string` | Yes | Hashtag name without the # prefix. |
| `rank` | `integer` | Yes | Position of the hashtag in the trending ranking. |
| `region` | `string` | Yes | Country or region code the ranking covers. |
| `metrics` | `object` | Yes | Counters and measurements available for the result item. |
| `metrics.posts_count` | `integer` | Yes | Number of posts or posts associated with the trend. |

| `top_countries.score` | `number` | Yes | Score reported for the entry. |
| `video_ids` | `array<string>` | Yes | IDs of example videos that use the hashtag. |
