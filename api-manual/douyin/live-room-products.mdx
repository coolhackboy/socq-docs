# Get Douyin Live Room Products

Fetch normalized live room products data from Douyin.

Each successful task costs a fixed `0.10` credits.

## Request Body

```json
{
  "room_id": "7356742011975715619",
  "author_id": "2207432981615527",
  "results_limit": 20
}
```

## Use with MCP

| Interface | Value |
| --- | --- |
| REST | `POST /v1/douyin/live-room-products` |
| Compact MCP | `socq_execute` with `endpoint: "douyin/live-room-products"` |
| Typed MCP | `socq_douyin_live_room_products` |
| Exact-tool URL | `https://api.socq.ai/mcp?tools=douyin_live_room_products` |
| CLI | `socq douyin live-room-products` |

<Info>
A successful request returns a `task_id`. Poll it with `socq_get_task`, then read normalized records from `results.items`.
</Info>
