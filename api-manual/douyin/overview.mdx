# Douyin

| API | Method | Endpoint |
| --- | --- | --- |
| Video Details | `POST` | `/v1/douyin/videos` |
| Profiles | `POST` | `/v1/douyin/profiles` |
| User Videos | `POST` | `/v1/douyin/user-videos` |
| Video Search | `POST` | `/v1/douyin/search` |
| Video Comments | `POST` | `/v1/douyin/comments` |
| Live Room Details | `POST` | `/v1/douyin/live-room-info` |
| Live Room Products | `POST` | `/v1/douyin/live-room-products` |
