# Douyin

| API | Method | Endpoint |
| --- | --- | --- |
| Video Details | `POST` | `/v1/douyin/video-detail` |
| Profiles | `POST` | `/v1/douyin/user-profile` |
| User Videos | `POST` | `/v1/douyin/user-videos` |
| Video Search | `POST` | `/v1/douyin/video-search` |
| Video Comments | `POST` | `/v1/douyin/video-comments` |
| Live Room Details | `POST` | `/v1/douyin/live-room-detail` |
| Live Room Products | `POST` | `/v1/douyin/product-data` |
