# Get Douyin Comments

Fetch normalized comments data from Douyin.

Each successful task costs a fixed `0.10` credits.

## Request Body

```json
{
  "url": "https://www.douyin.com/video/7448118827402972455",
  "results_limit": 3
}
```

{/* mcp-usage:start */}
## Use with MCP

| Interface | Value |
| --- | --- |
| REST | `POST /v1/douyin/video-comments` |
| Compact MCP | `socq_execute` with `endpoint: "douyin/video-comments"` |
| Typed MCP | `socq_douyin_video_comments` |
| Exact-tool URL | `https://api.socq.ai/mcp?tools=douyin_comments` |
| CLI | `socq douyin video-comments` |

<Info>
A successful request returns a `task_id`. Poll it with `socq_get_task`, then read normalized records from `results.items`.
</Info>
{/* mcp-usage:end */}
