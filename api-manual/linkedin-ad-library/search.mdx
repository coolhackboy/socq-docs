```json
{
  "company": "Microsoft",
  "countries": [
    "US"
  ],
  "results_limit": 24
}
```

`results_limit` must be a multiple of the 24-record page size.

## Use with MCP and CLI

| Interface | Value |
| --- | --- |
| REST | `POST /v1/linkedin-ad-library/search` |
| Compact MCP | `socq_execute` with `endpoint: "linkedin-ad-library/search"` |
| Typed MCP | `socq_linkedin_ad_library_search` |
| CLI | `socq linkedin-ad-library search` |

The endpoint uses the asynchronous task flow and returns a task_id. Poll the task endpoint to read normalized results.
