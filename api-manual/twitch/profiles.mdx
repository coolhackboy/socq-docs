# Get Twitch Profiles

Fetch normalized profiles data from Twitch.

Each successful task costs a fixed `0.19` credits.

## Request Body

```json
{
  "username": "twitch"
}
```

{/* mcp-usage:start */}
## Use with MCP

| Interface | Value |
| --- | --- |
| REST | `POST /v1/twitch/profiles` |
| Compact MCP | `socq_execute` with `endpoint: "twitch/profiles"` |
| Typed MCP | `socq_twitch_profiles` |
| Exact-tool URL | `https://api.socq.ai/mcp?tools=twitch_profiles` |
| CLI | `socq twitch profiles` |

<Info>
A successful request returns a `task_id`. Poll it with `socq_get_task`, then read normalized records from `results.items`.
</Info>
{/* mcp-usage:end */}
