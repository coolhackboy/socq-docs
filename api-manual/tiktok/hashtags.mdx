# TikTok Hashtags

Collect public videos for one or more hashtags. A leading `#` is optional.

```json
{
  "hashtags": ["tutorial", "#python"],
  "results_limit": 50
}
```

{/* mcp-usage:start */}
## Use with MCP

| Interface | Value |
| --- | --- |
| REST | `POST /v1/tiktok/hashtags` |
| Compact MCP | `socq_execute` with `endpoint: "tiktok/hashtags"` |
| Typed MCP | `socq_tiktok_hashtags` |
| Exact-tool URL | `https://api.socq.ai/mcp?tools=tiktok_hashtags` |
| CLI | `socq tiktok hashtags` |

Use the JSON request body above as the nested `input` object for `socq_execute`, or pass the same fields directly to the typed tool. Typed tools also accept `_wait_seconds`, `_result_limit`, and `_idempotency_key`.

<Info>
  A successful collection returns a `task_id`. Continue with `socq_get_task` until the task succeeds, then read normalized records from `results.items`.
</Info>

See [MCP quickstart](/integrations/mcp) for the complete submission and polling flow.
{/* mcp-usage:end */}

`results_limit` defaults to 100 and applies to each hashtag.

Results use the normalized structure documented in [TikTok Videos](/api-manual/tiktok/videos), with `resource` set to `hashtags`. The matched hashtag and its available metrics are returned under `extra`.

## Standard Result Fields

Poll `GET /v1/tasks/{task_id}?view=standard` for the fixed result contract. The standard view maps source-specific field names and formats to the stable SocQ fields below; it does not infer or enrich values that the source did not provide. For MCP use `view`/`fields` on `socq_get_task` or `_result_view`/`_result_fields` on typed tools; CLI uses `--result-view`/`--result-fields`. Declared fields remain present when their value is `null`; use the task files for complete source data.

| Field | Type | Nullable | Description |

| `id` | `string` | Yes | Unique identifier for this result item. |
| `platform` | `string` | No | Platform the result belongs to, such as `instagram` or `linkedin`. |
| `resource` | `string` | No | SocQ resource represented by the result, such as `videos` or `comments`. |
| `type` | `string` | No | Category of the result item, such as `video`, `post`, or `comment`. |

| `collected_at` | `string` | No | Time SocQ collected or processed this result, in ISO 8601 format. |
| `name` | `string` | Yes | Hashtag or trend name. |
| `rank` | `integer` | Yes | Position of the trend in the source ranking. |

| `metrics.posts_count` | `integer` | Yes | Number of posts or posts associated with the trend. |
