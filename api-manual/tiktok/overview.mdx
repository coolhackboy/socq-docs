# TikTok API

TikTok endpoints use the same asynchronous task flow as the other Agent APIs.

| API | Method | Endpoint |
| --- | --- | --- |
| Profiles | `POST` | `/v1/tiktok/profiles` |
| Videos | `POST` | `/v1/tiktok/videos` |
| Comments | `POST` | `/v1/tiktok/comments` |
| Search | `POST` | `/v1/tiktok/search` |
| Hashtags | `POST` | `/v1/tiktok/hashtags` |
| Video Transcript | `POST` | `/v1/tiktok/video-transcript` |
| Live Room Info | `POST` | `/v1/tiktok/live-room-info` |
| Trending Feed | `POST` | `/v1/tiktok/trending-feed` |
| Followers List | `POST` | `/v1/tiktok/followers-list` |
| Following List | `POST` | `/v1/tiktok/following-list` |
| Comment Replies | `POST` | `/v1/tiktok/comment-replies` |
| User Videos | `POST` | `/v1/tiktok/user-videos` |
| Search Users | `POST` | `/v1/tiktok/search-users` |
| Song | `POST` | `/v1/tiktok/song` |
| Song Videos | `POST` | `/v1/tiktok/song-videos` |
| TikTok Popular Songs | `POST` | `/v1/tiktok/popular-songs` |
| TikTok Top Search | `POST` | `/v1/tiktok/top-search` |
| TikTok User Live | `POST` | `/v1/tiktok/user-live` |
| Audience Demographics | `POST` | `/v1/tiktok/user-audience` |
| Similar Accounts | `POST` | `/v1/tiktok/similar-users` |
| Reposts | `POST` | `/v1/tiktok/user-reposts` |
| Playlists | `POST` | `/v1/tiktok/user-playlists` |
| Hashtag Views | `POST` | `/v1/tiktok/hashtag-detail` |
| Sound Search | `POST` | `/v1/tiktok/search-music` |
| Live Search | `POST` | `/v1/tiktok/search-live` |
| Photo Search | `POST` | `/v1/tiktok/search-photos` |
| Trending Searches | `POST` | `/v1/tiktok/trending-keywords` |
| Creator Search Insights | `POST` | `/v1/tiktok/search-insights` |
| Live Ranking | `POST` | `/v1/tiktok/live-ranking` |
| Live Shopping | `POST` | `/v1/tiktok/live-products` |
| Fake Views Checker | `POST` | `/v1/tiktok/fake-views` |
| Comment Keywords | `POST` | `/v1/tiktok/comment-keywords` |

Submit a request, receive a `task_id`, then poll `GET /v1/tasks/{task_id}`. Successful task responses include normalized records under `results`.

For endpoints that accept multiple video URLs or hashtags, `results_limit` applies to each input item.
