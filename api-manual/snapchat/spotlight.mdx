# Get Snapchat Spotlights

Fetch normalized spotlights data from Snapchat.

Each successful task costs a fixed `0.19` credits.

## Request Body

```json
{
  "url": "https://www.snapchat.com/@queenhaley_13/spotlight/W7_EDlXWTBiXAEEniNoMPwAAYY2pnZnF0bG52AZslQsUdAZslQoRQAAAAAQ"
}
```

{/* mcp-usage:start */}
## Use with MCP

| Interface | Value |
| --- | --- |
| REST | `POST /v1/snapchat/spotlight` |
| Compact MCP | `socq_execute` with `endpoint: "snapchat/spotlight"` |
| Typed MCP | `socq_snapchat_spotlight` |
| Exact-tool URL | `https://api.socq.ai/mcp?tools=snapchat_spotlights` |
| CLI | `socq snapchat spotlight` |

<Info>
A successful request returns a `task_id`. Poll it with `socq_get_task`, then read normalized records from `results.items`.
</Info>
