## Workflow

1. Submit a task to the platform endpoint, for example `POST /v1/amazon/product-search`. The response returns a `task_id` right away.
2. Poll [Task Status](/api-manual/agent-api/status) with the `task_id`, or pass `callback_url` to receive a [callback](/api-manual/agent-api/callbacks).
3. Read normalized records under `results` when the task succeeds, or download raw JSONL from [Task Files](/api-manual/agent-api/files).
